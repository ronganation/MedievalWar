## 10. Reopening Conditions

A completed Realm Economy package may reopen only for a material trigger:

```yaml
valid_reopening_conditions:
  - new historical or project evidence changes an economic fact or owner boundary
  - two current authorities materially conflict
  - a shared contract changes in a way that affects the Realm
  - Registry Opening State save or migration work exposes a real defect
  - implementation discovery exposes an unrepresentable requirement
  - fixture compile runtime save replay rollback performance accessibility localization or balance evidence exposes a defect
  - a genuinely new external Realm creates a material reciprocal interface
  - an owner issues a controlling adjudication
invalid_reopening_reasons:
  - another Realm uses a different file structure
  - another Realm has a longer authority
  - equal file counts would look cleaner
  - another checklist update is being written
  - implementation has not begun
  - exact hashes or owner-adoption paperwork remain
  - more prose could be added
```
