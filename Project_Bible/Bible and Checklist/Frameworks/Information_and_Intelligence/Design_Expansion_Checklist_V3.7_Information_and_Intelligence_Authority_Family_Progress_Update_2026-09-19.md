## 1. Purpose

This standalone progress update records completion of the Information and Intelligence authority-family static-design sequence.

The completed family now provides:

- one shared constitution for information, knowledge, communication, secrecy, disclosure, intelligence, warning, deception, and counterintelligence semantics;
- one copy-first Agent System V2 modernization for mission actors, eligibility, capabilities, cover, access, exposure, risk, mission attempts, and owner-routed outcomes;
- retained military reconnaissance and command-communication specialists;
- retained Character Network, Diplomacy, Historical, religious, economic, Property, Supply, Province, Public Order, Government, and Realm AI ownership boundaries;
- a developed-Realm compatibility review across the materially developed Realm packages;
- an explicit Barcelona coverage correction;
- a current-authority index and legacy disposition register;
- a machine-readable source manifest and static check;
- an independent static closure review.

This update does not authorize implementation promotion.

## 9. Opening State and Advanced-Save Firewall

```yaml

  NewCampaignOnly:
    true

  ApplyOnce:
    true

  OwnerReceiptRequired:
    true

  PrecommitHashRequired:
    true

    true

    true

```

Advanced saves may not:

- reset knowledge, belief, warning, message, secrecy, compromise, or correction state to opening defaults;
- recreate dead, captured, retired, missing, or unavailable Agents;
- restore resolved missions or erased cover states;
- reveal hidden state because a definition exists;
- rebuild runtime knowledge or missions from static definitions;
- erase deception, compromise, communication, or warning history;
- remove Campaign divergence.
