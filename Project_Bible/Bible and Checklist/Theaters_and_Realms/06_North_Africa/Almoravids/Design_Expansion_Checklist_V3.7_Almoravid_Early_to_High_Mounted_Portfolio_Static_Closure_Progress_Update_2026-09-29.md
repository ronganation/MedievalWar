## 1. Purpose

This standalone Checklist 3.7 update records the completed static-design pass for the Almoravid Early-to-unified-High-Era mounted portfolio. It supplements the stable Design Expansion Checklist 3.7 and the current Almoravid military root README. It does not replace either authority.

This update records that the cavalry, combat-camel, commercial-protection, household, regional, mounted-skirmisher, mounted-crossbow, contract-service, progression, naming, routing, and emergence work has reached a strong stopping point for the current chronological scope. It also records the conditions under which later mounted work may reopen.

This update does not create a recruitment pool, unit instance, source population, rider, horse, camel, remount, weapon, ammunition allotment, officer cadre, Registry identity, Opening State binding, payload, importer instruction, runtime record, save migration, Unreal asset, or production authorization.
