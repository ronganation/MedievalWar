## 7. Comparative Balance and Faction Uniqueness Rule

Future stat construction must compare mechanically similar units across relevant realms and entities. Comparable tier establishes a broad value relationship, not an identical stat template.

```yaml
comparative_stat_rules:
  comparable_tier_requires_identical_stats: false
  same_weapon_family_requires_same_card: false
  faction_uniqueness_requires_mechanical_expression: true
  historical_source_and_provider_affect_card: true
  battlefield_role_affects_stat_distribution: true
  campaign_availability_and_recovery_affect_total_value: true
  strengths_require_costs_limits_or_tradeoffs: true
  current_profiles_are_primary_qualitative_inputs: true
```

A broadly comparable first-tier spear unit may differ by spear reach, shield protection, armor, formation quality, cohesion, offensive pressure, cavalry reception, fatigue, terrain behavior, command responsiveness, recruitment depth, service limits, political access, cost, replenishment, and recovery burden.

Flanders must therefore receive mechanically distinct expressions of the Connected March, the Count's Web, and the Mustered Web rather than cloned statistics with different names.

```yaml
reservation_rules:
  one_person_one_active_assignment: true
  one_weapon_or_harness_set_one_active_issue: true
  one_horse_one_active_assignment: true

  one_support_capacity_reserved_once: true
  research_creates_complete_unit: false
  building_creates_complete_unit: false
  wealth_creates_complete_unit: false
```

A developed source may support several possible families, but the same people, leaders, equipment, horses, ammunition, transport, stores, and political willingness cannot be reserved repeatedly. Roster breadth creates army-composition choices rather than simultaneous full-depth recruitment.
