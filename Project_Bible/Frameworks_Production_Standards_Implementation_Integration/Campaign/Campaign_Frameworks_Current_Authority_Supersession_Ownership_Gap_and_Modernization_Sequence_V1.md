## 1. Purpose

This audit reviews the five complete current physical Campaign-folder sources supplied for the workstream, assigns one explicit authority disposition to each file, records what must be preserved, identifies what is superseded or owner-routed, and establishes the smallest strong copy-first additive modernization sequence.

The audit does not rewrite the five sources, publish canonical Unreal symbols, activate Campaign Objective instances, populate Opening State, or authorize implementation. It prevents five disconnected edits and prevents older prototype documents from continuing as competing current authorities.

```text
Audit != Successor
Descriptive Unreal Proposal != Verified Project-Native Architecture
Legacy Vision != Current Runtime Contract
Useful Content != Continuing Authority
Copy-First Additive Modernization != Compression
```

## 13. Stop Conditions

Stop the modernization sequence if:

- the complete immediate substantive source is unavailable;
- a successor materially shortens or strips useful content without a justified removal ledger;
- a universal score or monolithic record is retained merely for implementation convenience;
- a candidate Unreal symbol is presented as verified current project architecture;
- Campaign Objective definitions create runtime instances or opening facts;
- the turn pipeline lets AI, presentation, events, or objectives mutate specialist state directly;
- an advanced save can be overwritten by scenario defaults;
- the Codex exposes hidden private or future information;
- a legacy source is deleted rather than retained as provenance;
- a new wrapper adds no substantive capability;
- implementation is started before the owner gates and static closure are complete.
