# 3. Runtime Ownership Review

Character Network is the sole writer of Network-side node references, participation, directed edges, contexts, relationship provenance, Network visibility, access paths, contact routes, directed loyalty/trust/interpersonal familiarity, relational patronage/fealty/obligations, political/dynastic/succession alignment, Network-side arrangement references, and derived Network results.

External owners remain authoritative for identity, lifecycle, activation, simulation tier, Development, Underage arrangements, Archetypes, Historical Memory, Reputation, Traits, offices, titles, claims, dynasties, law, formal authority, institutions, coalitions, contracts, promises, service, debt, and all substantive arrangements.

Derived query/result fields never become constitutional truth merely because they are displayed, cached, or consumed. The consuming owner remains sole writer of its own strategic state.

# 4. Save Ownership Review

Character Network saves only Network-owned authoritative state and necessary references. Typed arrangements, external identity, facts, memory, Reputation, Development, offices, titles, claims, dynasties, and authority remain in their owner partitions.

Opening State fields initialize new campaigns only. Advanced saves outrank defaults. Direction, asymmetry, context, provenance, visibility, contacts, information paths, external references, and deterministic continuation must survive save-load-save. Derived outputs regenerate unless an approved deterministic cache exists.

# 5. Migration Ownership Review

Migration Registries and migration runtime own source mappings, deprecated identifiers, mapping/migration versions, ambiguity, quarantine, dependencies, and completion. Character Network validates accepted Network records. External arrangement owners validate their substantive records.

Migration preserves exact source, raw values, canonical endpoints, direction, asymmetry, context, provenance, visibility, chronology, arrangement ownership, dependencies, versions, outcomes, and reasons. Unsupported mirroring, inferred loyalty or knowledge, role merging, and invented IDs, nodes, relationships, audiences, roles, or content are prohibited. Ambiguity enters quarantine. Conversion remains direct, deterministic, dependency-aware, and idempotent.

# 6. Validation Review

## Fatal

- A semantic field changes constitutional owner.
- Authoritative Network state has more than one writer.
- Directed relationship state lacks source, target, context, or required provenance.
- One-sided state is mirrored without evidence.
- Network participation overrides Foundation lifecycle, activation, simulation tier, or authority.
- Access becomes knowledge or information truth.
- Kinship, marriage, alliance, location, office, title, culture, religion, or access creates loyalty automatically.
- Network state duplicates or mutates an external owner.
- Network edge replaces a typed arrangement.
- Guardian, wardship, fosterage, or mentorship references create or merge substantive roles.
- Succession alignment creates claims, candidates, heirs, stages, recognition, installation, or transfer.
- Derived output mutates a consuming system.
- Mutable outcomes appear in definitions or later outcomes appear in Opening States.
- Migration guesses unresolved data, emits deprecated identifiers, accepts alias chains, or produces nondeterministic output.

## Warning

- A dimension lacks source, visibility, context, or strategic purpose.
- Summary duplicates authoritative dimensions or lacks invalidation.
- Familiarity duplicates Development-owned familiarity.
- Patronage, fealty, or obligation lacks a substantive external source where required.
- A persisted derived result lacks cache ownership and invalidation.
- Network evaluates irrelevant lightweight nodes routinely.
- Normal turns create excessive low-impact relationship decisions.

Every later exact implementation field must map to one semantic row or enter reconciliation/quarantine. One exact field cannot silently combine several constitutional meanings.
