# 1. Concise Verdict

Character Network constitutional ownership translates into **32 bounded implementation contracts**. Character Network is the sole writer of directed relationship state, Network-side context, relationship provenance, social visibility, current information-access pathways, contact routes, and Network-derived relational state.

External owners remain sole writers of identity, lifecycle, Development, Underage arrangements, Archetype, Historical Memory, Reputation, Traits, offices, titles, claims, dynasties, formal authority, law, and typed arrangements. Typed Arrangement References are links only. Derived outputs are read-only. Migration Registries retain mapping, ambiguity, and quarantine authority.

No contract name below is an implementation symbol, registry entry, Gameplay Tag, or ID.

# 3. Writer and Reader Authority Review

Every authoritative contract has one writer. Readers may inspect authorized state, emit source events from their own domains, propose commands, request queries, and consume bounded results. Readers never gain mutation authority.

Character Network writes Network references, participation, directed edges, contexts, relationship-side provenance, Network visibility, information paths, contacts, relational dimensions, external-arrangement references, and derived Network outputs. Character Network does not write identity, lifecycle, activation, Development, Underage arrangements, Archetype, Historical Memory, Reputation, Traits, positions, claims, dynasties, law, authority, institutions, alliances, contracts, or strategic outcomes.

AI reads, evaluates, explains, and proposes. AI never mutates authoritative state.

# 4. Save Ownership Review

Character Network saves only Network-owned state and necessary references: node references, participation, directed edges, dimensions, Network visibility, information paths, contacts, relational states, provenance, arrangement references, approved cache metadata, compatibility, and deterministic continuation.

External owners save their own identity, lifecycle, Development, Underage, Archetype, Historical Memory, Reputation, Trait, position, claim, dynasty, law, authority, institution, arrangement, migration, and global save truth.

Direction and asymmetry must survive save-load-save. Network participation remains distinct from Foundation activation. Opening State data initializes new campaigns only.
