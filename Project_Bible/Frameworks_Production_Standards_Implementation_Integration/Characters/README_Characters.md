## 1. Purpose

This folder contains the reusable Character frameworks, authoring standards, implementation contracts, consolidation workspaces, reconciliation packages, manifests, and static-closure evidence for Medieval War.

The Character family supports strategic political and personal causality while preserving the campaign map as the central play space. Character depth should change strategy, not create routine character-management clicks.

```text
Deep Simulation Internally
Selective Exposure Externally
Clear Strategic Consequences
```

This README is the folder navigation authority. It does not replace the substantive framework files, create Character state, approve Profile Standard Version 3, or authorize Unreal implementation.

## 8. Non-Negotiable Rules

- A person is not an Office, title, Dynasty, Household, Institution, Region, or Realm.
- A Claim is not ownership.
- Legitimacy is not capacity.
- Aptitude is not capacity.
- Capacity is not Experience.
- Experience is not Readiness.
- Readiness is not Eligibility.
- Eligibility is not authority.
- Authority is not performance.
- Children are not small adults.
- Legal majority is not full adult agency.
- Archetype is not identity.
- Trait is not destiny.
- Reputation is not objective truth.
- Historical Narrative and Memory are not fact.
- Relationships are directed and may be asymmetric.
- Kinship or alliance does not create loyalty or knowledge.
- Unknown is not zero.
- Static definitions cannot contain mutable outcomes.
- Opening State applies once to a new campaign and never overwrites an advanced save.
- Names and filenames are not primary IDs.
- Ambiguous identities or migrations require review or quarantine.
- AI reads, evaluates, explains, and proposes. Owners validate and execute.
- Character priorities are not Campaign Objective instances.
- Objective completion does not create people, equipment, labor, money, authority, or capacity.
