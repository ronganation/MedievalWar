## 1. Strong Framework Verdict

Diplomacy is a campaign system of bounded contact, authority, knowledge, bargaining, commitment, material feasibility, performance, consequence, and settlement. It is not one bilateral attitude number and it is not a detached conversation minigame.

Preserve the readable Medieval II campaign loop: contact a recognized actor, make a clear proposal, receive understandable reasons, counteroffer, accept, refuse, threaten, delay, fight, negotiate, and convert military or political results into visible terms. Modernize that loop through directional knowledge, multiple principals, explicit representation, reciprocal owner receipts, finite capacity, typed obligations, uncertain performance, breach procedure, continuity, and player-visible consequences.

```text
Observed Need, Pressure, Opportunity, Claim, Grievance, or Request
+ Actor-Visible Knowledge
+ Valid Principal and Representative
+ Resolved Counterparty and Matching Authority
+ Deliverable Communication
+ Explicit Terms and Alternatives
+ Specialist-Owner Feasibility
+ Reciprocal Acceptance and Ratification
= Staged Agreement

Staged Agreement
+ Required Owner Receipts
+ Atomic Commit
= Active Agreement

Active Agreement
+ Owner-Executed Performance
+ Evidence and Receipt
= Performed, Partially Performed, Delayed, Disputed, Breached, Suspended, Fulfilled, or Terminated State
```

## 30. Player Presentation and Workload
