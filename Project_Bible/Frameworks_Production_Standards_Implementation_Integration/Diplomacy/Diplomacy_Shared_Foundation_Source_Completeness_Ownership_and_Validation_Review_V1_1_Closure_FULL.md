## 1. Review Verdict

The shared diplomacy foundation is substantively strong enough to remain the controlling review-only candidate and to proceed to a bounded correction pass. It successfully establishes the missing common lifecycle from actor-visible information and authorized representation through negotiation, agreement, owner-routed performance, breach, and political settlement. It also preserves the critical separations between diplomacy and the systems that own people, authority, territory, forces, money, routes, institutions, historical truth, Opening State, and runtime execution.

The framework does not yet receive unconditional promotion. ## 4. Legacy Source Disposition Review

### 4.1 Vassalage System

**Preserved:** Preserved as the immediate extraction authority for the separate subordination successor. The foundation correctly limits itself to a shared interface.

**Corrected boundary:** Universal loyalty scales, automatic obligation bundles, automatic war entry, and automatic integration remain rejected.

### 4.2 Allied Coordination System

**Preserved:** Shared objectives, commitments, rally-location terms, consultation, command precedence, support responsibilities, withdrawal, and post-conflict settlement are represented.

**Corrected boundary:** Movement, timing, reinforcement, siege, naval, supply, and combat execution remain military-owned.

### 4.3 Agent System

**Preserved:** Representative, envoy, mission, communication, interception, and reporting interfaces are represented.

**Corrected boundary:** Agent class, level, or mission success cannot create mandate, agreement, or relationship mutation.

### 4.4 Prisoner and Captive System

**Preserved:** Ransom, exchange, release, hostage, safe-return, custody-reference, and peace-settlement interfaces are represented.

**Corrected boundary:** People are not resources, and payment does not automatically release or return a person.

### 4.5 Mercenary System

**Preserved:** External-service proposal, provider, pay, supply, command, arrival, withdrawal, breach, and owner-receipt interfaces are preserved.

**Corrected boundary:** Diplomacy creates no mercenary people, formations, equipment, horses, ships, market availability, or loyalty.

### 4.6 Event System

**Preserved:** Diplomatic triggers, presentation, choices, consequences, and follow-up interfaces remain possible.

**Corrected boundary:** Events do not own diplomatic truth or bypass owner validation.
