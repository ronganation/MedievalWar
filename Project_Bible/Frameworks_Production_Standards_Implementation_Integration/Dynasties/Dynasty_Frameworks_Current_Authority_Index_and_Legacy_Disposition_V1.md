## 1. Purpose

This index is the single current navigation, precedence, ownership, legacy-disposition, and anti-churn surface for the shared Dynasty framework family.

It identifies the five current substantive authorities, states which predecessor remains the immediate substantive source for each successor, records the correct reading order, prevents predecessor files from overriding their successors, and preserves the implementation boundary.

This index does not replace the five substantive authorities. It creates no Dynasty, Branch, Household, relationship, Succession Context, Founder Dependency state, AI strategy, Opening State record, Registry identity, save schema, gameplay payload, or Unreal asset.

```text
Index != Substantive Authority
Navigation != Ownership
Precedence != Runtime Activation
Supersession != Deletion
Legacy Provenance != Current Control
Static Closure != Implementation
```
