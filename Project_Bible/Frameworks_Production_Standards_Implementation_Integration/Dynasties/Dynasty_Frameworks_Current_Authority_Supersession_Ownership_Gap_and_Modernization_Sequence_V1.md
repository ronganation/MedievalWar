## 1. Purpose

This audit establishes the current authority, ownership, supersession, preservation, modernization, and stop-gate sequence for the shared Dynasty framework family.

It reviews the five recovered substantive sources as one constitutional portfolio rather than modernizing each file independently and allowing overlapping ownership to persist.

The audit must answer:

- which framework owns Dynasty structure;
- which framework owns directed inter-Dynasty relationships;
- which framework owns succession transitions;
- which framework owns generational AI evaluation and proposals;
- which framework owns founder-function concentration and continuity exposure;
- which legacy scores, cadence assumptions, and Unreal proposals require current disposition;
- which files need copy-first additive successors;
- whether any new shared Dynasty framework is substantively necessary.

```text
Framework Family Audit != Framework Rewrite
Ownership Clarification != State Transfer
Currentness Correction != Runtime Implementation
Dynasty Depth != Genealogy Micromanagement
```

### 2.1 Dynastic Succession

The succession authority defines Dynasty headship, title and office transitions, heirs, claimants, recognition, evidence, minority, regency, installation, transfer, consolidation, partition, usurpation, displacement, restoration, extinction, and crisis resolution.

Its strongest governing rule is:

```text
Succession != Holder ID Replacement
Claim != Ownership
Legitimacy != Capacity
Heir Exists != Transition Prepared
Dynasty Headship != Realm Title Succession
```

### 2.2 Dynasty AI

The Dynasty AI authority defines long-horizon survival, continuity, office strategy, claim prioritization, marriage strategy, branch management, restoration, accommodation, and generational proposal logic.

Its strongest governing rule is:

```text
Dynasty AI Supports The Campaign Game
Dynasty AI Does Not Replace The Campaign Game
```

### 2.3 Dynasty Network

The Dynasty Network authority defines Dynasty identity, politically relevant membership, heads, branches, households, continuity, extinction, restoration, and references to titles, offices, claims, institutions, and Realms.

Its strongest governing rule is:

```text
Dynasty != Branch != Household != Character != Title != Office != Institution != Realm != Region
```

### 2.4 Dynasty Relationship

The Dynasty Relationship authority defines directed inter-Dynasty edges, kinship, marriages, obligations, grievances, rivalry, cooperation, protection, subordination, claimant pressure, reconciliation, and active relationship summaries.

Its strongest governing rule is:

```text
Marriage != Alliance
Kinship != Loyalty
Rivalry != Permanent War
Subordination != Ownership
```

### 2.5 Founder Dependency

The Founder Dependency authority defines concentrated personal functions, substitute readiness, leadership redundancy, continuity plans, transition exposure, transition shock, and institutional resilience across Dynasties, Realms, Governments, institutions, armies, coalitions, titles, offices, and succession.

Its strongest governing rule is:

```text
Personal Strength != Institutional Strength
```
