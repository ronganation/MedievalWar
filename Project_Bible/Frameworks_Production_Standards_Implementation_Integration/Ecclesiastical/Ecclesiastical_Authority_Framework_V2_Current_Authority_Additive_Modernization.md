## 3. Current Purpose

This framework owns reusable ecclesiastical institution, office, occupancy, jurisdiction, appointment, patronage, privilege, protection, sanctuary, mediation, hospitality, communication, command, event, evidence interface, save, migration, determinism, performance, validation, and implementation-handoff contracts without owning Realm-specific religious content.

It exists to support strategically meaningful religious institutions without turning them into:

- one faction;
- one loyalty bar;
- one Realm opinion;
- one building chain;
- one Papal hierarchy;
- one automatic legitimacy source;
- one parallel Government;
- one universal clergy simulation;
- one universal religious owner.
