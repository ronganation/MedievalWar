## 3. Shared Compatibility Standard

A Realm package conforms when it:

1. preserves the separation of ruler, qadi, jurist, scholar, preacher, institution, community, office, holder, jurisdiction, property, and Government;
2. does not construct a Muslim Papacy or one universal religious hierarchy;
3. treats religious legitimacy, khutba recognition, juristic opinion, institutional recognition, and community Reception as typed and audience-specific;
4. preserves evidence, Unknown, IntentionalEmpty, ReviewOnly, and Quarantine states;
5. never creates people, offices, institutions, property, Treasury, forces, recruitment pools, obedience, or Opening State through shared definitions;
6. routes military, Government, Property, Economy, Population, Diplomacy, Historical, Character, Dynasty, and Campaign Experience consequences to their owners;
7. preserves new-campaign-only Opening State and advanced-save protection;
8. treats AI as proposal-only;
9. preserves the three-track temporal constitution;
10. retains faction differentiation rather than duplicating file shapes.

```text
Shared Capability != Identical File
Shared Contract != Identical Institution
Realm Variation != Shared-Authority Conflict
Combined Realm Authority != Missing Specialist Authority
Unknown Holder != Missing Function
Definition != Opening State
Opinion != Judgment
Judgment != Enforcement
Recognition != Obedience
```
