# 5. Save Review

## Definition Content

All Governance Structure Definition fields remain versioned content. They are not copied into mutable campaign state. A save may retain only the compatible content/version reference required for deterministic interpretation.

## Saved mutable state

The Governance save partition may preserve fields from:

- Governance Administration State;
- Governance Reach State;
- Governance Capacity State;
- Governance Performance State.

External references remain references. Their substantive state remains in the owning partition.

## Derived results

Governance Performance Result fields regenerate from authoritative state. They are not authoritative saved state. If a deterministic cache is later approved, only cache metadata and invalidation references may persist under a separately approved contract. This inventory creates no cache or save schema.

## Save invariants

1. Definition, mutable state, and derived results remain separate.
2. Advanced saves outrank Opening State defaults.
3. Opening references initialize new campaigns only.
4. Vacancies do not erase Governance structures.
5. Dead or inactive people do not retain living administrative agency.
6. External records remain external references.
7. Reach does not reload as jurisdiction or control.
8. Capacity does not reload as readiness, authority, or Domain Capacity.
9. Performance does not reload as legitimacy, authority, Crown Authority, or Regional Authority.
10. Derived results cannot become mutable truth after load.
11. Unknown, ambiguous, deprecated, or incompatible references fail safely or quarantine.
12. Save-load-save preserves Governance state, source references, versions, and deterministic continuation.
