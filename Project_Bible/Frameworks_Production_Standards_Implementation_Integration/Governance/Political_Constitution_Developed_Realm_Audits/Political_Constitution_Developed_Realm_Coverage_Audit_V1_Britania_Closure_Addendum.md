## 6. Example Classification for Future Theater Mechanics

A future concept such as controlling or dominating Britania must first be classified before design work begins.

```yaml
classification_questions:
  - IsTheConceptAVictoryConditionObjectiveOrAchievement
  - IsTheConceptATheaterAIObjective
  - IsTheConceptARealmTitleClaimOrGovernmentTransformation
  - IsTheConceptAMilitaryOccupationOrTerritorialControlState
  - IsTheConceptADiplomaticRecognitionOrSettlement
  - IsTheConceptARegionalIntegrationPublicOrderOrAdministrativeCapacityState
  - IsTheConceptAPlayerFacingSummaryOfSeveralOwnerStates
```

```text
Theater Control Summary != New Territory Owner
Theater Objective != Automatic Claim
Military Occupation != Political Settlement
Dominance != Uniform Government
Victory Condition != Opening State
Shared Theater Mechanic != Same Realm File Repeated Four Times
```

The correct implementation may be a Theater-level query or objective that consumes Realm, Province, Military, Diplomacy, Political Constitution, Historical, and Victory-condition owners. It must not silently overwrite them.
