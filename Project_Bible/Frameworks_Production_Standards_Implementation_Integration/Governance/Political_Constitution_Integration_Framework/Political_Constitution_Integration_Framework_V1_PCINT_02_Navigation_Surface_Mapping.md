## 1. Purpose and Decision Boundary

This document completes PCINT-02 by mapping one preferred existing navigation, current-authority, specialist-integration, readiness, or cross-owner control surface for each developed Realm reviewed by the Political Constitution coverage audit.

It does not create a new Realm authority, reopen Realm coverage, patch any physical source, promote any Opening State or Registry record, or authorize implementation.

```text
Navigation Surface Mapping != Source Patch
Cross Reference != Ownership Transfer
Static Framework Promotion != Runtime Promotion
Realm Coverage Closure != Implementation Readiness
No Change != Missing Capability
```

## 11. PCINT-03 Patch Eligibility

A mapped surface becomes eligible for an owner-approved documentation-only patch only when all conditions are met.

```yaml
pcint_03_entry_requirements:
  - ExactPhysicalCurrentSourceResolved
  - CurrentAuthorityAndSupersessionStatusConfirmed
  - PerFileOwnerApprovalRecorded
  - CompleteSourceRetrievedAndPreserved
  - StableDependencyContractAccepted
  - BeforeFingerprintRecorded
  - PatchLimitedToNavigationOrDependencyRouting
  - NoRealmFactOrOwnerBoundaryChanged
  - RollbackSourceRecorded

pcint_03_exit_requirements:
  - CompleteSourcePreserved
  - CrossReferenceAddedOnceAtPreferredSurface
  - NoDuplicateReferenceAddedToSubstantiveAuthorities
  - AfterFingerprintRecorded
  - LiteralCompletenessCheckPassed
  - OwnerReceiptRecorded
  - RegistryOpeningStatePayloadRuntimeAndUnrealMutationRemainFalse
```

France and Norway are not patch-eligible until their current navigation surfaces are recovered. The Almoravid movement-state is not Realm-patch-eligible until its final Realm package index is recovered, although the North Africa Theater index may be considered separately by the Theater owner.
