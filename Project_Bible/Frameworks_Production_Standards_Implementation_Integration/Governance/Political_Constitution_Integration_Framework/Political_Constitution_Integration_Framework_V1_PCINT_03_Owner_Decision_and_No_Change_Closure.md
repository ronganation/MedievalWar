## 2. Basis

The decision rests on four completed controls:

1. The framework owner accepted the Political Constitution Integration Framework as the current shared integration authority for static design and documentation routing only.
2. The developed-Realm coverage audit closed the reviewed Realm set without identifying a substantive governance gap requiring a new Realm authority.
3. PCINT-02 identified one preferred existing navigation or control surface for each reviewed Realm, with no new navigation file required.
4. PCINT-03 established that per-file patches require material routing benefit, exact current-source verification, complete source preservation, owner approval, fingerprints, and rollback.

The current package state does not require twenty-one mechanical README or index edits merely to repeat a dependency already controlled at the shared-framework level.
