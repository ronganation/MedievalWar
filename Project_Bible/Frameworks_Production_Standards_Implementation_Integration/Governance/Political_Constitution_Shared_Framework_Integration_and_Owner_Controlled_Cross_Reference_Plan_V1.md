## 3. Integration Principle

```text
Shared Framework != Shared Government
Cross-Reference != State Transfer
Dependency Declaration != Runtime Binding
Review-Only Candidate != Promoted Authority
Realm Coverage Closure != Implementation Readiness
```

The framework may connect participation, recognition, legitimacy, political escalation, Government Transformation, Realm AI explanation, and persistence handoff across distributed owners. It may not replace Realm-specific Government, Law, Title, Office, Claim, Succession, Character, Dynasty, Ecclesiastical, Diplomacy, Opening State, Registry, or Theater authorities.
