## 7. Historical Momentum Interface

Historical Memory may supply audience-specific reception, preservation, grievance, commemoration, sacred memory, dynastic memory, regional memory, military memory, evidence strength, contradiction, and legacy as owner-backed inputs to Historical Momentum.

```text
Memory Reception != Momentum
Legacy != Momentum
Momentum Influence != Memory Mutation
Historical Basis != Current Pressure Automatically
```

Momentum V2 owns admission, intensity, persistence, escalation, saturation, contradiction, counter-Momentum, decline, dormancy, resolution, and retirement.

Historical Memory continues to own the Memory state used as one possible Momentum input.

## 8. Historical Emergence Interface

Historical Memory may provide:

- remembered claimant identity;
- restoration narratives;
- sacred or dynastic expectations;
- regional grievance or unity memory;
- preserved educational or institutional context;
- evidence supporting historical identity review;
- narrative opportunity for dynamic equivalents.

Historical Memory does not create an emergence candidate, canonical Character identity, Character activation, Office, Title, Claim, command, Archetype, Development, or strategic function.

```text
Memory Opportunity != Emergence Eligibility
Emergence Eligibility != Character Activation
Legacy Figure != Living Agency
Historical Identity Evidence != Permission To Duplicate
```

## 9. Campaign Experience Boundary

Historical Memory may provide owner-backed inputs to Objective eligibility, explanation, blockers, recovery, Standing interpretation, Designation eligibility, and player-facing Campaign history.

- activate an Objective;
- advance Objective lifecycle;
- confirm Standing or a Designation;
- execute a Reward;
- declare Victory;
- create a Claim, Office, Title, agreement, force, or material capacity.

## 11. Current Update and Cadence Model

The earlier phrase `Run monthly or on scenario-defined cadence` no longer controls current evaluation.

Historical Memory uses:

- immediate event-driven dirty flags for material changes;
- bounded strategic-turn review;
- audience-local recalculation;
- Historical Date eligibility where relevant;
- Biological milestones where a living witness or Character lifecycle matters;
- Campaign Season effects where preservation, travel, warfare, ritual, or access makes the season relevant;
- deferred review when evidence, owners, or visibility remain unresolved.

Historical Memory must not evaluate every Memory against every Character each frame.

## 13. Persistence, Migration, Determinism, and Quarantine

Historical Memory persistence must retain:

- stable semantic identity references;
- owner versions and rule versions;
- effective dates;
- source-state hashes;
- audience-specific Reception;
- Evidence custody and preservation state;
- Narrative competition and contradiction;
- Commemoration and suppression history;
- review, reversal, and retirement rules;
- trace and validation references.

Ambiguous identity, provenance, custody, participation, chronology, or owner state must enter quarantine rather than being guessed.

Migration repeat-application idempotence remains a future migration-owner validation requirement and is not claimed as already validated.
