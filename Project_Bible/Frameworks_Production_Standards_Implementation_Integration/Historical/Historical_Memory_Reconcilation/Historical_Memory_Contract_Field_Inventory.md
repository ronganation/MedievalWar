# 3. Runtime Ownership Review

## Historical Memory authoritative state

Historical Memory is the sole writer of authoritative runtime state for:

- Evidence Runtime State;
- bounded Witness/Testimony References;
- Narrative Runtime State;
- Memory Reception State;
- Memory Tradition State;
- Historical Record State;
- Commemoration State;
- Preservation State;
- Legacy State;
- Historical Memory-side Source Provenance.

Historical Memory writes the Historical Memory side of Fact Reference only. Campaign History or the applicable strategic owner retains fact and participation truth.

## External authoritative state

- Character Foundation owns canonical person identity, lifecycle, activation, and core person state.
- Character Network owns directed relationship and current information-access state.
- Reputation Authority owns current character-audience Reputation.
- Institution, Office, Claim, Title, Law, Succession, and other strategic systems own their respective truth.
- Migration Registries and migration runtime own mappings, migration records, and quarantine.

## Derived state

Historical Memory Query/Influence Result fields are derived. They never become constitutional truth merely because they are displayed, cached, or consumed. The consuming system remains the sole writer of strategic outcomes.

## Runtime non-ownership

Historical Memory does not own:

- deterministic facts;
- authoritative participation;
- person identity or life state;
- current directed relationships or information access;
- current character Reputation;
- institutions, offices, titles, claims, laws, succession, legitimacy, or authority;
- physical settlements, buildings, or logistics;
- AI execution.

# 4. Save Ownership Review

## Historical Memory save partition

Historical Memory saves only owner-specific authoritative state and necessary references:

- evidence and testimony state;
- narrative state;
- memory/narrative reception;
- memory traditions;
- historical records as information objects;
- commemorations;
- preservation, contradiction, suppression, decay, loss, recovery, and revival;
- legacy;
- bounded provenance;
- references to facts, people, institutions, audiences, Network state, and Reputation sources;
- deterministic continuation and reason data where required.

## Opening State initialization

Opening State fields apply once when constructing a new campaign. They may initialize only evidence, testimony, narratives, reception, traditions, records, commemorations, preservation, and legacy that validly exist by the opening date. Advanced saves always outrank Opening States.

## Normally not saved as authority

- commands;
- transient query payloads;
- derived influence results;
- presentation summaries;
- validation results not required for trace/migration;
- caches without approved ownership, invalidation, and deterministic reconstruction.

## External save ownership

Facts and participation, person state, Network state, current Reputation, institutions/offices, claims/titles/law, physical assets, mappings/quarantine, and save-version truth remain in their owning partitions. Historical Memory stores references only.

# 5. Migration Ownership Review

Migration Registries and migration runtime own source mapping, deprecated references, versions, ambiguity, quarantine, provenance, and migration completion.

Historical Memory validates accepted destination records. Migration may not:

- reassign ownership;
- invent IDs or registries;
- create facts, participation, audiences, witnesses, evidence, narratives, memories, or content;
- use labels or filenames as identity;
- collapse fact, evidence, narrative, reception, memory, Reputation, and legacy;
- bypass quarantine.

## Required migration evidence

Each migration record preserves:

- exact source location;
- raw and normalized source value;
- semantic classification;
- source owner and subject references;
- audience and chronology evidence where needed;
- destination contract;
- mapping version;
- ambiguity and validation results;
- quarantine and dependencies;
- outcome and completion status;
- deterministic ordering and reasons.

Conversion must be direct, versioned, idempotent, dependency-aware, and deterministic.

# 6. Validation Review

## Fatal

- A semantic field changes its constitutional owner.
- Historical Memory writes fact or participation truth.
- Evidence/testimony lacks required fact, source, witness, presence, or chronology.
- A dead witness creates new testimony.
- Narrative assertion becomes fact.
- Memory Reception substitutes for current character Reputation.
- A Historical Record creates legal validity, title, claim, office, property, jurisdiction, legitimacy, or authority.
- Historical Memory duplicates Network or Character Foundation truth.
- Reception lacks a bounded audience.
- Definition data contains mutable runtime outcomes.
- Opening State contains later history or overwrites an advanced save.
- A derived query directly mutates a consumer.
- Legacy restores living agency.
- Migration invents an ID, source, audience, witness, participation, content, or destination.
- Unknown or ambiguous source data is guessed rather than quarantined.
- Alias chains or deprecated modern outputs are accepted.
- Equal state, inputs, versions, and seed produce unequal authoritative results.

## Warning

- Evidence lacks complete source, quality, custody, contradiction, or preservation handling.
- Narrative lacks evidence, author/sponsor, audience, contradiction, or lifecycle handling.
- Testimony context duplicates current Network state rather than references it.
- Historical Record lacks custody or preservation path.
- Commemoration lacks prerequisites or bounded audience effect.
- Preservation lacks external cause references.
- Legacy lacks historical basis.
- Provenance lacks source owner, source version, or chronology.
- Derived results are persisted without cache ownership and invalidation.
- Processing creates repeated low-impact player prompts.

## Completeness rule

Every later exact implementation field must map to exactly one semantic row here or be flagged for reconciliation/quarantine. One exact field may not silently combine several constitutional meanings. Multiple exact fields may implement one semantic row only when they retain the same owner and boundaries.
