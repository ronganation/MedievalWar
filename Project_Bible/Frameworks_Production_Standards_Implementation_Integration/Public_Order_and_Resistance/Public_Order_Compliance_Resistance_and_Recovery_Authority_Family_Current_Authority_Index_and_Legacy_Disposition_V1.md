## 1. Authority-Index Verdict

The Public Order family is controlled by one bounded shared integration authority and a distributed specialist-owner architecture. Public Order is not a universal loyalty, obedience, unrest, fear, or rebellion currency. The shared integration authority interprets and routes owner-backed conditions into typed public-response cases, candidate states, proposals, receipts, explanations, and recovery reviews without absorbing Province, Population, Law, Government, Political Constitution, Military, Historical, Information, Economy, Property, Religion, Diplomacy, Character, Dynasty, Realm AI, Registry, Opening State, save, migration, or runtime ownership.
