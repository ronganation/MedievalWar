# Overview

The Allied Coordination System governs how factions cooperate militarily, politically, strategically, and logistically.

The purpose of this system is to ensure allied factions act as genuine partners rather than independent actors sharing a diplomatic agreement.

The system controls:

- Rally Points
- Shared Objectives
- Coalition Warfare
- Reinforcement Logic
- Army Coordination
- Siege Coordination
- Supply Coordination
- Vassal Support
- Religious Coalitions
- Defensive Pacts
- Offensive Pacts

This system integrates with:

- Diplomacy & Trade System
- Vassalage System
- Religious System
- Campaign Sustainment & Logistics System
- Court Politics System
- War Weariness System
- Siege System
- Naval System
- AI Master Template

---

# Core Philosophy

Allied factions should be capable of:

- Fighting together
- Marching together
- Sieging together
- Defending together
- Retreating together

An alliance should feel like a strategic partnership.

# Rally Point System

Allies may establish Rally Points.

A Rally Point acts as a gathering location for military operations.

Examples:

- York
- London
- Edinburgh
- Jerusalem
- Constantinople

---

## Rally Point Effects

Friendly armies:

- Move toward objective
- Synchronize arrival
- Await reinforcements

This reduces isolated attacks.

# Army Coordination

Armies evaluate nearby allies.

Examples:

If Army Strength:

Army A
= 2000

Army B
= 1500

Enemy
= 5000

Result:

Both armies wait and coordinate.

Avoids suicidal attacks.

---

# Coordinated Assaults

Allied armies may launch synchronized attacks.

Requirements:

- Shared objective
- Similar arrival times
- Supply feasibility

Effects:

- Combined strength
- Improved success chance
- Better reinforcement behavior

---

# Reinforcement Logic

Allied armies may reinforce each other.

The AI evaluates:

- Distance
- Roads
- Supply
- Attrition
- Enemy Threat

---

## Emergency Reinforcement

If ally is attacked:

Nearby armies evaluate:

- Can I arrive?
- Is intervention worthwhile?
- Can supply support movement?

Coalitions
