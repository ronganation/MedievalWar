# Overview

The Dynamic Narrative Arc Framework governs long-term campaign stories.

Narrative Arcs exist above:

- Events
- Event Chains
- Objectives

and below:

- Victory Conditions
- Historical Outcomes

Narrative arcs provide direction without removing player agency.

History is influenced.

History is not scripted.

---

# Core Philosophy

Events create moments.

Event chains create situations.

Narrative arcs create stories.

Narrative arcs should emerge naturally through:

- AI actions
- Player actions
- Characters
- Dynasties
- Governments
- Religion
- Culture
- Warfare
- Trade

The systems generate history.

# Multiple Outcomes

Every arc has multiple endings.

Example:

Norman Ambition

Possible Endings:

- Norman Conquest
- Norman Failure
- Norman Alliance
- Anglo-Saxon Survival
- Norse Intervention

No single outcome is guaranteed.
