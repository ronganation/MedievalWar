# Economy System
Medieval War — Systems/Economy_System.md

## Overview
The Economy System defines how wealth is generated, distributed, taxed, traded, invested, and lost across the Medieval War campaign.

It governs:
- Taxes  
- Trade  
- Resource production  
- Settlement economy  
- Province economy  
- Faction-wide economy  
- Upkeep  
- Recruitment cost scaling  
- Guild economic bonuses  
- Inflation & prosperity  
- Supply & logistics costs  
- Era-based economic evolution  
- Economic events  
- Diplomatic economic treaties  

This system integrates with:
- Settlement Classification System  
- Province System  
- Supply System  
- Cultural Geography System  
- Religious System  
- Diplomacy & Trade System  
- Guild Politics System  
- Court Politics System  
- Law & Policy System  
- Vassalage System  
- War Weariness System  
- Event System  
- Population System  
- Agent System  
- Era Progression System  
- AI Master Template  

The Economy System is the backbone of all campaign decision-making.

# ============================
# 1. Economic Layers
# ============================

The Medieval War economy operates on four layers:

1. **Settlement Economy**  
2. **Province Economy**  
3. **Faction Economy**  
4. **Global Economy**

Each layer influences the next.

---

# ============================
# 2. Settlement Economy
# ============================

Each settlement type contributes differently.

## 2.1 Cities
- Highest tax income  
- Highest trade value  
- Highest population growth  
- Strong guild presence  
- Strong cultural pressure  
- Strong religious influence  

## 2.2 Castles
- Low tax income  
- Low trade value  
- High military upkeep  
- High supply cost  
- Military guild bonuses  

## 2.3 Villages
- Food production  
- Basic tax income  
- Resource extraction  
- Low trade value  

## 2.4 Ports
- Naval trade  
- Naval supply  
- Maritime guild bonuses  
- Vulnerable to blockades  

## 2.5 Trade Hubs
- High trade value  
- Merchant Guild bonuses  
- Banking House bonuses  
- Diplomatic trade leverage  

## 2.6 Resource Sites
Resource sites produce raw materials:

- **Mines** → Iron, silver, gold  
- **Timber Camps** → Wood  
- **Horse Pastures** → Horses  
- **Grain Fields** → Food  
- **Fisheries** → Fish  
- **Salt Works** → Salt  

Resource production affects:
- Recruitment  
- Upkeep  
- Trade  
- Supply  
- Diplomacy

# 3. Province Economy
# ============================

## 3.1 Province Economic Identity

- Resource mix  
- Guild dominance  

Examples:

- **Merchant Province**  
- **Agricultural Province**

- **Religious Province**  

## 3.2 Province Economic Bonuses

- Road networks

- Sea lanes  
- Province edicts  
- Governor traits  
- Guild influence
