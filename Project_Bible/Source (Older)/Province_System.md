# Province System
Medieval War — Systems/Province_System.md

## Overview
The Province System defines how provinces function as macro‑regions that unify multiple settlements under a single administrative, cultural, religious, economic, and logistical identity.

It governs:
- Province identity  
- Province loyalty  
- Province culture  
- Province religion  
- Province stability  
- Province supply networks  
- Province trade networks  
- Province governors  
- Province edicts  
- Province events  
- Province rebellions  
- Province diplomacy  
- Province integration with Era Progression  

This system interacts directly with:
- Settlement Classification System  
- Cultural Geography System  
- Religious System  
- Loyalty & Public Order System  
- Diplomacy & Trade System  
- Supply & Logistics System  
- Agent System  
- Court Politics System  
- Faction Identity System  
- Era Progression System  
- Economy & Resources System  
- Event System  
- AI Master Template  

Provinces are the backbone of regional identity, stability, and strategic planning.

# ============================
# 1. Province Structure
# ============================

Each province contains:
- 1–4 settlements  
- 1 province capital  
- 1 province governor  
- Province cultural identity  
- Province religious identity  
- Province supply network  
- Province trade network  
- Province loyalty  
- Province stability rating  

Provinces act as the “macro layer” above settlements.

# ============================
# 3. Province Loyalty
# ============================

Province Loyalty represents how loyal the entire region is to the ruling faction.

### Province Loyalty Levels
- 0–25%: Hostile (rebellion likely)  
- 26–50%: Unstable (high unrest)  
- 51–75%: Mixed (manageable)  
- 76–100%: Loyal (stable, bonuses)  

### Province Loyalty Sources
Positive:
- Strong governor  
- Cultural alignment  
- Religious alignment  
- Low taxes  
- Strong garrison  
- High supply  
- Trade prosperity  
- Era stability  
- Court Advisor missions  
- Diplomat missions  

Negative:
- Cultural mismatch  
- Religious mismatch  
- High taxes  
- Oppressive policies  
- Supply collapse  
- Trade collapse  
- Corrupt governor  
- Agent sabotage  
- Province famine  
- Province devastation  
- Era instability  

Province Loyalty directly influences:
- Settlement loyalty  
- Public order  
- Rebellion chance  
- Recruitment  
- Supply stability

# ============================
# 6. Province Stability
# ============================

Province Stability is a composite score based on:
- Province loyalty  
- Cultural loyalty  
- Religious loyalty  
- Supply stability  
- Trade stability  
- Governor traits  
- Settlement stability  
- Era progression  

Province Stability ranges:
- –100 to +100  

Effects:
- High stability → bonuses to economy, recruitment, supply  
- Low stability → unrest, rebellions, economic collapse

# ============================
# 7. Province Governors
# ============================

Each province has a **Province Governor**.

### Governor Responsibilities
- Manage province loyalty  
- Manage province stability  
- Manage taxes  
- Manage cultural integration  
- Manage religious integration  
- Manage supply networks  
- Manage trade networks  
- Issue province edicts  
- Counter agent activity  
- Influence settlement development  

### Governor Traits
- Just / Cruel  
- Builder / Neglectful  
- Pious / Cynical  
- Diplomatic / Hostile  
- Cultural Strategist / Cultural Oppressor  
- Religious Strategist / Religious Oppressor  
- Logistician / Inept  
- Corrupt / Honest  

Governor traits heavily influence:
- Province loyalty  
- Settlement loyalty  
- Cultural conversion  
- Religious conversion  
- Supply stability  
- Trade value

# ============================
# 11. Province Rebellions
# ============================

Province rebellions occur when:
- Province loyalty < 30%  
- Cultural loyalty < 30%  
- Religious loyalty < 30%  
- Supply collapse  
- Trade collapse  
- Governor corruption  
- Era instability  
- Agent sabotage  

Rebellion Types:
- Cultural Rebellion  
- Religious Rebellion  
- Economic/Guild Rebellion  
- Noble Rebellion  
- Military Rebellion  
- Multi-settlement Province Rebellion  

Province rebellions are larger and more dangerous than settlement rebellions.

# ============================
# 13. Era Integration
# ============================

### Early Era
- Weak province governance  
- High instability  
- Frequent rebellions  
- Cultural fragmentation  

### High Era
- Stronger governors  
- Province edicts unlocked  
- Stronger cultural integration  
- Stronger religious institutions  

### Late Era
- Highly stable provinces  
- Strong bureaucracy  
- Strong economic influence  
- Reduced rebellion success  

Era progression affects:
- Province loyalty  
- Province stability  
- Supply networks  
- Trade networks  
- Cultural conversion  
- Religious conversion

# ============================
# 14. AI Integration
# ============================

AI uses provinces to:
- Evaluate invasion targets  
- Manage governors  
- Manage taxes  
- Manage supply  
- Manage trade  
- Manage cultural conversion  
- Manage religious conversion  
- Trigger or avoid rebellions  
- Trigger or avoid civil wars  
- Choose settlement specialization  
- Choose diplomatic strategies  

AI adapts across eras:
- Early: reactive  
- High: political  
- Late: bureaucratic
