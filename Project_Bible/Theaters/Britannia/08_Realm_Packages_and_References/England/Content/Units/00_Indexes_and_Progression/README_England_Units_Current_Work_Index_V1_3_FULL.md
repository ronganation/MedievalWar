## 1. Purpose

This README is the practical entry point for continued England unit work. It records the unit profiles, mounted and missile progression maps, roster controls, and organization files currently surfaced from the England package search. Its central rule is simple: check what already exists before creating or redoing anything.

This is a navigation and work-control file. It does not replace the England realm README, roster authority, admission matrix, recruitment architecture, progression maps, family reconciliations, or unit profiles.

## 2. Search Boundary

This index uses only results tied to the England package and England unit work. Results from other realms, generic shared-framework locations, unrelated repositories, and old external copies are excluded from the working inventory.

The connected search surface did not return a complete recursive folder dump when queried with the full SharePoint folder URL. Therefore this is a current search-grounded index, not a claim that every file in the folder has been enumerated. A file not listed here is not proven absent.

## 3. Start Here

Before any new unit file is created or any old unit is redone:

1. Search the exact proposed display name.
2. Search the exact proposed filename.
3. Search likely legacy names and aliases.
4. Check the applicable progression map.
5. Check the roster admission and source architecture.
6. Open the existing profile in full when one is found.
7. Use copy-first additive successor work rather than parallel recreation.
8. Update this index after the accepted package is placed in the England folder.

## 14. Conversation-Generated Files Are Not Automatically Repository Files

A file created in chat is not treated as part of the England package until it is uploaded and returned by a current England-folder search. Conversation artifacts should be classified as one of:

```yaml
conversation_artifact_status:
  - AcceptedAndUploaded
  - PendingOwnerReview
  - ComparisonMaterialOnly
  - SupersededBeforeUpload
  - RejectedDuplicateRisk
```

This prevents the current folder index from being polluted by files that were never accepted into OneDrive.
