The Dublin Command Warship is Ireland's scarce High urban flagship. The vessel converts a suitable hull, fleet leader, officers, messengers, signal hands, pilots, selected retainers, port authority, and prepared Dublin fleet into one compact command system. The unit coordinates and protects a fleet. The unit does not replace the repeatable Dublin Warship or become a disguised Great Warship.

## 1. Direct Unit Verdict

The **Dublin Command Warship** is Ireland's scarce High urban fleet-command, high-value escort, rapid-relief, signal-coordination, and decisive-boarding vessel.

The player recruits the vessel to **establish one compact command network, assign one mission-critical priority, coordinate the prepared fleet, direct one rapid relief or formation correction, commit selected retainers for one decisive action, and recover before command casualties or overcommitment collapse coordination**.
