This README controls the organization and routing of Scotland's High-era naval portfolios. The High folder contains two distinct path-owned subfolders rather than a flat shared roster:

- `Scoto_Norse_and_Western_Sea`
- `Traditional_Scottish`

Each path owns its canonical unit profiles, README, progression authority, provider logic, recruitment architecture, visual language, and implementation family. Shared Britannia vessels remain external and conditional.
