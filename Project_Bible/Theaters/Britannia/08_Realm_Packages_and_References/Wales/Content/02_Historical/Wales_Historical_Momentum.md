## 1. Concise Verdict

Wales opens on 1 January 1062 under living, broad, but unevenly integrated supremacy. Historical Momentum models the directional pressures created by that condition: founder dependence, regional friction, frontier danger, vulnerable Mercian support, dynastic continuity reserves, Irish Sea opportunity, institutional continuity, and future succession exposure. Momentum is not an objective, event queue, prophecy, score of legitimacy, or command.

```text
Evidence != Momentum
Memory != Momentum
Pressure != Objective
Pressure != Event
Pressure Strength != Probability
Reinforcement != Historical Truth
Resistance != Cancellation
Collision != Automatic Crisis
Dormant != Absent
Later Outcome != Guaranteed Direction
```

## 2. Authority and Ownership

Historical Momentum owns pressure identity, direction, intensity band, reinforcement, resistance, decay, redirection, collision, visibility, and Momentum-side AI explanation. Evidence owns proposition support. Chronology owns temporal compatibility. Uncertainty owns bounded interpretation. Memory owns audience reception. Opening State and specialist owners control exact state and activation. Emergence owns pathway lifecycle.

```yaml

  Defined: pressure definition exists
  Eligible: prerequisites pass
  Active: owner-approved pressure state exists
  Reinforced: compatible inputs increase persistence or intensity
  Resisted: countervailing inputs reduce effect
  Redirected: pressure changes target or expression
  Colliding: two or more pressures interact
  Decaying: supporting inputs weaken
  Dormant: pressure remains defined without active effect
  Resolved: current pressure instance ends without deleting history
```
