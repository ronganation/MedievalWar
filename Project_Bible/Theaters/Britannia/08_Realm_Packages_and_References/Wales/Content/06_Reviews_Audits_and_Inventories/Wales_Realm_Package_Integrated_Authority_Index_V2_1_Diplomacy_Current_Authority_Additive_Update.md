## 1. Purpose

This index is the current human-readable navigation and status surface for the Wales Realm package. It identifies the controlling authority chain, current and retained files, source-to-successor relationships, authority ownership, specialist coverage, Opening State and Registry status, evidence artifacts, unresolved decisions, validation state, and smallest safe next gates.

This index is organizational and navigational. It does not replace substantive authorities, approve owner decisions, activate Opening State records, create Registry entries, migrate saves, modify Unreal assets, or certify implementation.

```text
Index Entry != Substantive Authority
```
