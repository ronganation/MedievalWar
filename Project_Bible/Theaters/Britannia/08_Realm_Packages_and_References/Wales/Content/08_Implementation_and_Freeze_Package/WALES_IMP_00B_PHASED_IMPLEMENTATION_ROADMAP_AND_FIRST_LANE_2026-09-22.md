```text

Phase 1: Campaign Initialization
Phase 2: Transaction and Recovery
Phase 3: Historical Emergence

Phase 5: Realm AI and Personality
Phase 6: Cross-Realm and Theater completion or reconciliation

```

### Dependency rationale

```text
Campaign Initialization precedes later family application because it defines the deterministic review-only opening context.
Transaction and Recovery precedes broader candidate application because it defines rollback, conflict, save, and migration protection.
Historical Emergence consumes opening context but cannot guarantee later history.
Information and Intelligence supplies bounded knowledge summaries and uncertainty handling.
Realm AI and Personality consumes review-only information and historical context but cannot execute decisions or commands.
Cross-Realm and Theater work is reconciled after Realm-local foundations because existing Wales source already contains one detected seam.
```
