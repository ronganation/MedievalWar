## Purpose

This document defines the modern Wales Character Network authority for the campaign opening.

It replaces the legacy model of:

- dynastic blocs;
- mutual relationship pairs;
- universal influence levels;
- automatic loyalty;
- automatic political alignment;
- automatic Church support;
- later rulers active at opening;
- Historical Memory acting as a Network participant;
- a single office-titled St Davids person.

The Wales Character Network owns:

- directed person-to-person relationship edges;
- asymmetric mutable relationship dimensions;
- relationship contexts;
- relationship provenance;
- relationship visibility;
- information-access pathways;
- contact routes;
- Network participation state;
- omission traces;
- Network query results.

The Wales Character Network does not own:

- person identity or lifecycle;
- dynasty identity or membership;
- titles, offices, institutions, claims, or succession;
- Governance structures or authority;
- historical facts, evidence, narrative, memory, or Momentum;
- traits, reputation, archetypes, or development;
- armies, resources, territory, public order, or laws;
- household, guardianship, custody, education, or fosterage arrangements.
