## 2. Campaign Theater Constitution

The controlling Campaign Theater framework defines a Theater as an organizational, visual, strategic, and data-facing layer above Realm packages and below the campaign world. Theater membership creates context and interfaces. It does not create obedience, ownership, alliance, shared knowledge, uniform identity, route access, or scripted outcomes.

```yaml

- PrimarySecondaryFrontierMaritimeExpeditionaryAndLegacyAssociationTypes
- TheaterPackageOrganization

TheaterDoesNotOwn:
- RealmOrFactionIdentity
- PoliticalOrderIdentity
- TitlePossessionOrHierarchy
- TerritorialOwnershipOrControl
- CharacterDynastyHouseholdOfficeOrRelationshipState
- DiplomacyWarPeaceAllianceOrRecognition
```
