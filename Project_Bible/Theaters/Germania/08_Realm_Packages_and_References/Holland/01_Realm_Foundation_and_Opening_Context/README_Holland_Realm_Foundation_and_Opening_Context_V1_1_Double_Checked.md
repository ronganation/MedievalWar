## 1. Folder Purpose

`01_Realm_Foundation_and_Opening_Context` contains the small set of high-level authorities that establish what Holland is, how the Holland campaign should feel, what the Holland Realm package owns, and how later specialist work must be integrated without duplication or premature implementation.

This folder is the constitutional entry point for the Holland Realm package. It is not a general storage location for every document that affects Holland. Character, dynasty, military, history, ecclesiastical, government, economy, administration, campaign, AI, presentation, unit, and roster work must remain in their established specialist folders.
