## 4. Core Separations

Symbol is not historical proof.  
Color is not ownership.  
Map shading is not control.  
Control is not property.  
A route line is not access or capacity.  
A building icon is not a canonical building.  
A portrait is not identity, agency, office, or current location.  
A banner is not an opening heraldic fact.  
Music is not cultural proof.  
Voice direction is not a claim of exact pronunciation or dialect.  
Flavor text is not canonical state.  
A tooltip is not a substitute for ownership routing.  
Localization must not change game meaning.  
Accessibility must not be an optional afterthought.  
An attractive composition must not project later history backward.
