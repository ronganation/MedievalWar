## Teutonic Order Current Authority and Folder Guide

### 1. Purpose

This README is the navigation guide for:  
Project\_Bible/Theaters/Germania/08\_Realm\_Packages\_and\_References/Holy\_Orders/Teutonic\_Order  
It covers the Teutonic Order authority files held directly in this folder and the contents of the Units and Decision\_Review subfolders. It is navigation only and does not replace any authority, unit profile, decision review, evidence record, or static check.

### 2. Recommended folder boundary

The Teutonic\_Order folder should own the full Teutonic-specific package:
- Teutonic institutional emergence and military-service foundation;
- historical reconsideration and conditional factionization;
- Order-state ownership boundaries and narrow corrections;
- government, population, recruitment, service, recovery, grants, leadership, campaign, and fortress authorities;
- Teutonic unit admission and collision decisions;
- current Teutonic battlefield unit profiles;
- companion static checks.  
The following Teutonic-specific institutional foundation files are now correctly housed directly inside this folder:
- Germania\_Teutonic\_Order\_Institution\_Emergence\_Mission\_Patronage\_Houses\_Membership\_and\_Military\_Service\_Authority\_V1\_FULL.md
- Germania\_Teutonic\_Order\_Institution\_Emergence\_Mission\_Patronage\_Houses\_Membership\_and\_Military\_Service\_Authority\_V1\_Static\_Check.json  
These files establish the Teutonic institutional foundation and belong beside the later Teutonic authorities. Their placement inside Teutonic\_Order does not change their substantive standing.  
Do not move the Templar, Hospitaller, portfolio-wide, or other Order-specific authorities into this folder.

This folder is a static Teutonic design package. The folder does not by itself authorize:
- an opening Teutonic Order or Order-state in January 1062;
- opening Teutonic units or recruitment rights;
