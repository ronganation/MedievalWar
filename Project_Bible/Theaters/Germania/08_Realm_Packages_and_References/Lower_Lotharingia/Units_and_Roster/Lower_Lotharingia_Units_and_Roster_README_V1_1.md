## 12A. Root Change-Propagation Matrix

| Change | First update | Second update | Third update | Root README action |
|---|---|---|---|---|
| Unit profile version or identity | Unit profile | Relevant progression authority if affected | Era README | Update version, count, role, and closure references |
| Unit moves between eras or role folders | Unit profile and owner decision | Progression authority | Both affected era READMEs | Update root matrix and folder routing |
| Progression authority changes | Progression authority | Affected era README | Foundation authority only if broad philosophy changes | Update authority version and relationship summary |
| Settlement, pool, stats, or AI authority activates | Domain authority | Relevant implementation register | Era README only where inventory status changes | Record domain authority without rewriting unit identity |
| Late Era layer is authorized | Late completeness authority | High-to-Late progression authorities | New Late README | Add Late folder only after owner approval |
