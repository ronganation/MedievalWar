It classifies candidate claims, records blockers, identifies owner routes, and prevents broad orientation from becoming false exactness.

```text
Decision file != Opening State
Supported orientation != exact binding
Known person != known opening location
Existing government != known office roster
Royal association != direct property
Instrument category != opening inventory
Unknown != empty
Later historical event != opening condition
```
