## 1. Purpose

This index identifies the current static authority for each Saxon Billung Power capability, preserves predecessor and umbrella provenance, records known physical aliases, and controls package navigation before the README, readiness audit, content freeze, Opening State admission, or Unreal implementation planning.

```text
Index Selection != Substantive Authority
Search Result != Physical Manifest
Physical Alias != New Authority
Predecessor != Current Owner
Current Owner != Opening State
Static Completeness != Implementation Readiness
```

The index does not delete, archive, rename, overwrite, or demote any physical file. Those actions require a later recursive physical manifest and explicit owner approval.

## 2. Inventory Confidence Classes

```yaml
ConfidenceClasses:
  VerifiedCurrent:
    meaning: Successor returned by refreshed OneDrive search with current version metadata

  CurrentByAcceptedSequence:
    meaning: Successor completed and accepted in the Saxon development sequence but not confirmed by the latest search result set

  PreservedPredecessor:
    meaning: Earlier substantive source retained for provenance and rollback after a successor was accepted

  UmbrellaIntegrationProvenance:
    meaning: Broad source retained for migration history but not allowed to override split current owners

  AssessmentOrHandoffRecord:
    meaning: Decision evidence and sequence history, not a substantive domain owner

  AliasOrDuplicateReview:

```
