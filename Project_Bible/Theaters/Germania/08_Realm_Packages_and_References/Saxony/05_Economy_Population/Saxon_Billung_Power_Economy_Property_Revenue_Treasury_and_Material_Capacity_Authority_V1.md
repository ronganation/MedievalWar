## 3. Player-Facing Economic Thesis

> Build an executable Billung power base from rights that are actually possessed, administered, collected, delivered, stored, and protected, rather than treating ducal title or dynastic memory as money.

The player must decide which rights can be verified, which holdings can be administered, which burdens are collectible, which promises can be delivered, which stores must be protected, and which ambitions should be narrowed when capacity is absent.
