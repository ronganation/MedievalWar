## 1. Purpose

This matrix separates the people, titles, households, dynasties, properties, institutions, regional actors, local entities, routes, service sources, and external relationships that the provisional Saxon Billung package must coordinate without owning by default.

The matrix answers one question:

> Can a Billung-centered playable package exist as a coherent regional power without pretending that ducal title, family identity, household, direct property, ecclesiastical institutions, comital powers, royal rights, local communities, and all territories called Saxon form one owner?

It does not publish a canonical Realm identity. It does not create a character authority, dynasty authority, household authority, integrated core, property portfolio, military roster, Opening State, Registry package, payload, importer, or runtime state.

```text
Owner Separation != Political Fragmentation By Default
Coordination != Ownership
Ducal Title != Realm
Realm Candidate != Uniform Territory
Billung Dynasty != Every Saxon Actor
Household != Dynasty
Household != Government
Property != Jurisdiction
Jurisdiction != Revenue
Ecclesiastical Institution != Ducal Department
External Relationship != Realm Asset
Named Actor != Opening Binding
```
