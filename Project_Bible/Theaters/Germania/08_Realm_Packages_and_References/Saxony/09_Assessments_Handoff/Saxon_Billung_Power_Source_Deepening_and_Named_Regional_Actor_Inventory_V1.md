## 1. Purpose and Bounded Verdict
This authority deepens the evidence base for the provisional Saxon package and creates the first named regional-actor inventory. It tests whether a coherent Billung-centered playable core can be supported without claiming all Saxony, converting the ducal title into uniform control, erasing ecclesiastical and comital owners, or back-projecting later conflicts and territorial forms.
