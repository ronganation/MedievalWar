## 1. Purpose

This file is the current human-readable entry point for the Iberia Theater package. It defines bounded Theater scope, folder roles, current authority routing, known cross-Theater changes, the visual-reference boundary, present assessment gaps, package progress, and the smallest safe next action.

This index does not replace substantive Iberia Theater authorities or Realm packages. Folder placement does not prove ownership, activate a Theater association, create a Realm or faction, apply an Opening State, authorize an importer, or mutate the Unreal project.

## 2. Current Scope

The Iberia Theater working scope includes:

- the Iberian Peninsula;
- Pyrenean crossings and adjacent trans-Pyrenean interfaces required by Iberian campaigns;
- Atlantic and western Mediterranean approaches relevant to Iberian campaign interaction;
- the Balearic island system and its mainland and maritime interfaces;
- bounded North African diplomatic, commercial, religious, military, knowledge, route, maritime, and Historical Emergence interfaces;

## 5. Campaign-Actor Classification Route

The established architecture defines four actor tiers: full factions, autonomous associated actors, governed or institutional actors, and emergent or External Lock actors. Failure to qualify as a full faction does not erase a polity.

For current assessment and package planning, use readable labels mapped to the established tiers:

```yaml
current_actor_labels:
  FullOpeningRealm:
    source_alignment: TierI_FullFaction
    package_depth: FullRealmAuthorityChain
  DeployablePolity:
    source_alignment: TierII_AutonomousAssociatedActorOrBoundedFactionShell
    package_depth: CompleteForOwnedSystemsWithoutAutomaticFullRealmExpansion
  DependentOrSubordinatePolity:
    source_alignment: TierIIOrTierIIIAccordingToIndependentConsent
    package_depth: DependencyTerritoryMilitaryAndEmergenceCoverage
  LocalPowerNetwork:
    source_alignment: TierIII_GovernedOrInstitutionalActor
    package_depth: LocalAuthorityAndForceAccess
  HistoricalEmergenceCandidate:
    source_alignment: TierIV_EmergentOrExternalLock
    package_depth: DormantDefinitionAndOwnerGatedActivation
  ExternalInterface:
    source_alignment: TierIVOrExternalOwnerReference
    package_depth: IberiaCompatibilityOnly
```

Do not use generic rebels as the default representation for organized cities, island administrations, fortress commands, communities, military households, frontier powers, ports, or culturally and politically developed local actors. Battle deployment, human campaign selection, Primary-faction status, and sovereign Realm status remain separate decisions.
