# PART I. PURPOSE, SCOPE, AND OWNERSHIP

## 1. Purpose

This authority adapts the shared Military-Religious Orders framework to Iberia. It defines how later native orders and internationally rooted order branches can emerge, establish presence, negotiate with exact Iberian realms and institutions, hold property, receive fortress custody, mobilize finite forces, employ associated contingents, and persist through political change.

It does not create a named order package. It does not create order units. It does not add any order to the January 1, 1062 opening.
