# Iberia Character Rule-Derived Selection Reference Model V1

Run with:

```bash
python reference_model.py
```

The model loads `model_input.json`, evaluates candidates through explicit knowledge, availability, domain fit, evidence, access, obligation, risk, minimum-score, and deterministic tie-break rules, then writes:

- `model_output.json`
- `REFERENCE_MODEL_REPORT.md`

The data is synthetic and noncanonical. The package does not modify Registry, Opening State, saves, Unreal files, or canonical Iberia content.
