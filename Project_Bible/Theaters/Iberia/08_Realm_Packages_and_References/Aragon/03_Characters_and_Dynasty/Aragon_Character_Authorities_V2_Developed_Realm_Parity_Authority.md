# 1A. Developed Character-Cast Thesis

Aragon opens with a deliberately compact cast whose value comes from distinct strategic agency, not genealogical volume. Ramiro anchors the founder-dependent union. The two adult Sanchos create separate succession, property, delegation, and command questions without predetermined rivalry. García and Sancha remain bounded developing dynasts whose later church and diplomatic importance is possible rather than scripted.

```text
Person != Destiny
Kinship != Loyalty
Legitimacy != Capacity
Eligibility != Authority
Adult Age != Automatic Command
Later Office != Opening Readiness
Historical Importance != Unlimited Simulation Depth
```
