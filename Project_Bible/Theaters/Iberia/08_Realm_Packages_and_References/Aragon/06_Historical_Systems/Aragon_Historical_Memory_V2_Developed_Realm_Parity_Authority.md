# 1. Concise Verdict

Implement a compact opening memory set centered on nine memory definitions:

1. `memory.aragon.sancho_iii_partition_legacy`
2. `memory.aragon.ramiro_received_aragon`
3. `memory.aragon.sobrarbe_ribagorza_union`
4. `memory.aragon.pamplonese_seniority`
5. `memory.aragon.earlier_graus_failure`
6. `memory.aragon.san_juan_patronage`
7. `memory.aragon.bigorre_dynastic_connection`
8. `memory.aragon.pyrenean_routes`
9. `memory.aragon.regional_customs`

Seven memories are suitable for bounded opening use. Two remain ReviewOnly pending stronger source-specific authoring:

- `memory.aragon.earlier_graus_failure`
- `memory.aragon.regional_customs`

Opening holders should not all receive the same memory. Each holder receives a separately authored memory state with:

- narrative;
- source and evidence;
- confidence;
- visibility;
- salience;
- interpretation;
- reinforcement history;
- contradiction state;
- strategic tags;
- owner references.

The authority rejects:

- realm-wide omniscient memory;
- memory as objective fact;
- memory as direct claim, loyalty, relationship, or title ownership;
- one universal prestige or grievance score;
- fixed emotional reactions;
- later events inserted as opening memories;
- memories of Ramiro's future death, the later Battle of Graus, Barbastro, papal vassalage, Roman-rite reform, the 1076 Pamplona union, later Jaca institutions, later conquests, or the Crown of Aragon;
- Memory directly activating Momentum, Emergence, war, diplomacy, or AI commands.

Primary classification: **Implement holder-specific opening memories where evidence and strategy justify them. Keep uncertain narratives ReviewOnly. Preserve fact, evidence, narrative, reception, memory, pressure, and emergence as separate owned records.**

- **Campaign History** owns facts and events that actually occurred in the campaign state.

- **Character Network** owns directed relationships and grievance or trust state.

- **Governance** owns current regional recognition and administration.
- **Historical Momentum** owns pressure derived from current state and memory-informed interpretation.
- **Historical Emergence** owns conditional pathways.
- **Realm AI** reads memory summaries and proposes commands.

## 2.4 Non-negotiable separation

```text
Fact
!= Evidence
!= Narrative
!= Reception
!= Memory
!= Relationship
!= Claim
!= Pressure
!= Emergence
!= Outcome
```

A memory may be accurate, incomplete, biased, disputed, legendary, inherited, or contradicted. A strong memory is not automatically a true fact or legal right.

# 6. Sancho III's Partition Legacy

## 6.1 Identity

- **Memory ID:** `memory.aragon.sancho_iii_partition_legacy`
- **Status:** CanonicalProposed
- **Subject:** the dynastic division following Sancho III's death
- **Opening activation:** Yes, holder-specific

## 6.2 Canonical bounded narrative

> The present political order descends from a division of Sancho III's wider family dominions among close kin. Aragon, Pamplona, Castile, Sobrarbe, and Ribagorza remain connected by descent, remembered precedence, and competing interpretations, but they are not one administratively unified polity in 1062.

## 6.3 Strategic meanings

Possible interpretations include:

- shared kinship enables communication;
- shared kinship creates rivalry as well as cooperation;
- earlier division gives no automatic right to current territory;
- succession and entitlement require title-specific evidence and recognition;
- external courts may interpret the settlement differently;
- the Aragonese branch remains part of the wider Jiménez world.

## 6.4 Proposed holders

- Ramiro: high salience, strong confidence, private and public variants
- legitimate Sancho: medium-high salience, inherited and court-taught
- elder Sancho: medium-high salience, relevant to birth and inheritance standing
- García: medium salience, bounded by age and education
- Sancha: medium salience, bounded by age and household communication
- Aragonese branch: public dynastic narrative

## 6.5 Prohibited effects

The memory does not create:

- automatic Pamplonese seniority in runtime law;
- claims;
- alliance;
- hostility;
- knowledge of external private positions;
- future Pamplona succession.
