## 10. Review, Quarantine, External, and Prohibited References

### 10.1 ReviewOnly

ReviewOnly references may appear for validation and authoring control. ReviewOnly references cannot generate initialization requests that create runtime entities.

### 10.2 Quarantine

Quarantine references block dependent initialization and produce structured diagnostics. Quarantine never resolves through display name or fuzzy matching.

### 10.3 External locks

External locks identify expected external owners and entity types. Local package application cannot create external private state, reverse relationships, consent, resources, readiness, or title state.

### 10.4 Prohibited references

The package rejects:

- Gothic Barcelona Cathedral opening alias;
- ambiguous person aliases;
- Prince of Olèrdola quarantine title;
- deprecated IDs;
- alias chains;
- later-history records;
- any ReviewOnly record in an active collection.
