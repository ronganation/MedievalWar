## 3. Modern Medieval II Design Doctrine

Historical Memory exists to make the campaign map more intelligible and causally rich. It changes how qualified holders interpret service, succession, patronage, taifa pressure, frontier risk, regional government, institutions, burials, relics, promises, grants, commands, and settlement. It must not become detached lore, one universal opinion bar, a casus belli permission gate, fixed historical destiny, or constant court-event administration.

## 6. Authority Thesis

León-Castile Historical Memory owns holder-specific and audience-specific interpretations of already owned facts, experiences, claims, ceremonies, conflicts, service, promises, institutions, places, victories, defeats, grants, burials, relics, and precedents. Memory changes interpretation and political use. It does not create the remembered fact, claim, title, office, relationship, army, resource, sovereignty, authority, or outcome.
