## 3. Planning Vocabulary

### Candidate

A historically supported entity category suitable for owner review. It is not a canonical identity.

### Owner proposal

The system or future realm authority expected to define, validate, mutate, or lock the entity. It is not ownership approval.

### External-lock request

A request that the owning realm or shared registry provide a canonical reference and protect against duplicate Seville ownership.

### Quarantine

A claim that cannot enter active content until evidence and owner approval are sufficient.

### Definition-only

Static description of what an entity is. It contains no mutable opening or runtime outcome.

### Scenario candidate

A possible January 1062 fact requiring later Opening State evidence and approval. No scenario candidates are instantiated here.

- names and display variants;

A concise realm summary, strategic pressures, capital and map identity, succession readiness, external demands and a few meaningful choices. It may not become authority.
