## 11. Stop Conditions

Stop and preserve evidence if:

- the expected Unreal project path is absent or points to a different project;
- controlling project documentation cannot be identified;
- OneDrive and project-local authorities conflict;
- a required interface is missing and has no owner;
- the proposed approach requires a Seville-local replacement framework;
- an inspection command would mutate source or generated assets;
- a batch would collapse the three temporal tracks;
- Unknown or IntentionalEmpty would become a guessed default;
- fixtures, rollback, or deterministic evidence cannot be produced;
- a tool attempts Registry, real-payload, advanced-save, or broad Unreal mutation without its gate.
