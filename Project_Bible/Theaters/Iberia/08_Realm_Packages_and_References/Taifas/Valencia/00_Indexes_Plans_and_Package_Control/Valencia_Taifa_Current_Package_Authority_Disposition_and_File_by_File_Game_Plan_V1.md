## 1. Purpose

This file controls Valencia's modernization from the current thirteen-file package to an organized, current-authority, implementation-ready Realm package. It prevents stale `NEXT_FILE` footers, earlier closeout language, duplicate visual controls, unsupported runtime activation, and premature machine-readable production from deciding the workstream.

The plan is deliberately file by file. Major Markdown authorities remain individual work items. Small JSON companions may be produced in bounded batches only after their substantive source is complete. The plan itself should be updated after each completed substantive file so the package always exposes the current source, successor, evidence boundary, and smallest safe next action.
