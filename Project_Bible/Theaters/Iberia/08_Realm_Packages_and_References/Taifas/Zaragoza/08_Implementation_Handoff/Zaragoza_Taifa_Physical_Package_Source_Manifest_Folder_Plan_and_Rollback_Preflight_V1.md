## 19. Stop Conditions

Stop the physical package lane if:

- either candidate root is selected without opening controlling repository authorities;
- a search result is treated as a verified physical path;
- same-named files are deleted or overwritten before full comparison;
- a source hash, byte count, or currentness class is invented;
- Valencia, Badajoz, or Seville structure is copied for symmetry;
- a provenance source is removed merely because a successor exists;
- a shared or external definition is duplicated;
- an existing Zaragoza package is found and not reconciled additively;
- Package Integration Owner approval is absent;
- work crosses into Registry, Opening State, payload, importer, Unreal, or runtime mutation.

Continue read-only root, path, source, and duplicate verification.
