## 1. Purpose and Method

This file reconciles the strongest currently recoverable evidence around the January 1, 1062 Italia Theater boundary. It distinguishes facts supported by current sources, broad orientation, date-sensitive claims, design interpretation, unresolved questions, and prohibited back-projection.

This file intentionally does not pretend that January 1 can always be reconstructed to settlement-level precision from broad historical overviews. When exact evidence is incomplete, the project may choose a bounded Modern Medieval II opening posture that preserves the known political problem, active historical pressure, player agency, and plausible alternative outcomes. Such a posture must be labeled as design interpretation rather than historical fact.

```text
Historical Reconciliation != False Precision
Opening Accuracy != Frozen Historical Outcome
Design Interpretation != Fabricated Historical Claim
Date Window != Date-Only Script
Historical Pressure != Guaranteed Victor
Opening Flexibility != Anachronistic Realm
```

## 12. Historical Flexibility Doctrine for the Opening

The Modern Medieval II opening should privilege **pressure, capacity, and choice** over forced reenactment.

```yaml
OpeningDesignDoctrine:
  historical_boundary:
    rule: BeginFromDefensibleJanuary1_1062ActorsClaimsAndControl
  date_window:
    rule: NearOpeningEventsMayCreateEligibilityPressureOrDecisionContent
    automatic_activation: false
  historical_momentum:
    rule: StrongHistoricalPressuresCanShapeAIGoalsEventsKnowledgeAndLegitimacy
    guarantees_outcome: false
  historical_emergence:
    rule: LaterIdentityMayAppearWhenWorldStateAndOwnerThresholdsPass
    creates_resources: false
  alternative_history:
    rule: AllowedWhenProducedByPlausibleOwnerControlledState
    unconstrained_freeform: false
```
