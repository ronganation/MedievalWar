## 3. Decision Vocabulary and Effects

Use only the authorized dispositions:

- `AcceptAsCurrentSubstantiveCivilAuthority`
- `RetainAsOwnerReviewCandidate`
- `AcceptAsSupportingEvidenceOnly`
- `RequireMetadataCorrectionBeforeAcceptance`
- `RequireCurrentnessReconciliation`
- `RejectFromCivilSystemsFreeze`

For each authority, `AcceptAsCurrentSubstantiveCivilAuthority` would bind only the named lane's source for ReviewOnly structural definitions with immutable path/bytes/hash; it would not authorize active values, Registry or Opening State mutation, runtime materialization, payload/importer/save/migration work, or promotion. This is a possible future option, not the current decision. No candidate's version, index family heading, completeness claim, or structural design boundary is an owner receipt.

`AcceptAsSupportingEvidenceOnly` would not satisfy the generic validator's substantive-source requirement. `RequireMetadataCorrectionBeforeAcceptance` and `RequireCurrentnessReconciliation` are only appropriate if the relevant evidence is later identified. `RejectFromCivilSystemsFreeze` would exclude the source from the lane; it would not erase or alter the source. `RetainAsOwnerReviewCandidate` preserves the present status and is the recommendation for the seven material sources and Presentation.

Diplomacy additionally has a family-level outcome vocabulary in Section 6. Until an outcome is explicitly chosen by the authorized owner and Package Control validates it, `ConflictHoldRetained` remains the recommended and controlling state.
