A separate Southern Norman intelligence file therefore requires a narrower overlap test before admission.

## 16. Information and Intelligence Candidate Review

The information and intelligence family is real at project level. The shared bounded assessment explicitly identifies a gap between Realm-specific information authorities and specialist agent and military-intelligence systems. The shared military reconnaissance framework separately covers campaign reconnaissance, intelligence, deception, and counterintelligence. The Agent System also includes spies, missions, infiltration, counter-espionage, hidden-agent discovery, terrain and route scouting, and battle intelligence.

The Southern Norman package, however, already owns deep knowledge-holder, message, authentication, interpretation, deception, secrecy, audience, diplomacy, agreement, and external-relations contracts. A new Realm file must therefore target only capabilities still unowned after that V1.1 authority, rather than duplicating its content.

```yaml
InformationIntelligenceDisposition:
  substantive_project_family: true
  standalone_southern_norman_authority_admitted_now: false
```
