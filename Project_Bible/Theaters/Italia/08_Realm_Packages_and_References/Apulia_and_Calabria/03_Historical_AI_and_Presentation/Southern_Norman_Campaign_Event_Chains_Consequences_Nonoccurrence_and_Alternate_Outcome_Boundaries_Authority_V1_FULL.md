## 1. Authority Verdict

This authority closes the documented substantive gap for **Event-chain and Consequence Boundaries**. It defines cross-domain, source-bound event-chain families as static review contracts. It specifies evidence, date, world-state, identity, owner, duplication, interruption, cancellation, nonoccurrence, alternate-outcome, persistence, and rollback boundaries.

Every family is `ReviewOnly`. A definition is not a trigger, event instance, state mutation, or prediction. A date window is evidence context, never a sufficient condition. Nonoccurrence, delay, abstention, cancellation, and a valid alternate outcome remain first-class results. No historical figure, conquest, transformation, battle, treaty, succession, or other outcome is guaranteed.

Historical Emergence is referenced only as a conditional owner-gated interface. This authority does not admit a person, create an identity, activate emergence, or turn an emergence candidate into an objective reward.

## 2. Scope and State Distinctions

This authority owns static definitions and contracts only. It does not own historical fact admission, the state of another domain, or any running campaign record.

```text
HistoricalCondition
!= EventChainDefinition
!= RuntimeTrigger
!= EventInstance
!= ConsequenceDefinition
!= AppliedEffect
!= SaveRecord
```

- A **HistoricalCondition** is a source-backed statement with provenance, confidence, scope, and uncertainty. It is not a present campaign fact.
- An **EventChainDefinition** is a static, owner-routed review model. It does not execute.
- A **RuntimeTrigger** would evaluate current owner-published state under a separately authorized simulation contract. None is created here.
- An **EventInstance** is a runtime occurrence with a unique, persistent lifecycle. None is created here.
- A **ConsequenceDefinition** describes a possible owner-routed response, including delay or no action. It is not applied.
- An **AppliedEffect** belongs to a separately authorized domain-owner transaction. No effect is applied here.
- A **SaveRecord** is persistent runtime state subject to a separately approved schema and migration design. No save record or schema is defined here.

## 4. Common Initiation, Evidence, and Date Contract

The word **initiation** below means that a future, separately authorized review may be considered. It never means that a runtime trigger fires.

1. A proposal requires a current, source-bound definition and a specific initiating condition supported by the responsible owner.
2. Evidence must identify provenance, source version, effective scope, confidence, known contradictions, audience, and the authority entitled to publish the world-state fact.
3. No universal numeric evidence threshold is invented. The relevant source owner must publish its threshold; an absent or disputed threshold means hold or abstain.
4. A date window must come from the accepted source and be applicable to the scenario. A date by itself can never initiate, identify, or complete a chain.
5. World-state requirements must come from the owner of the actual political, civil, diplomatic, ecclesiastical, character, military, naval, or material state. A Campaign Content definition cannot manufacture missing state.
6. Decision branches include defer, reject, no action, continue review, alternative proposal, and nonoccurrence. No branch is presumed chosen.
7. A consequence is a static description of an option and its owner route. It has no effect until a separate, valid owner transaction is authorized.
8. A delayed consequence is not a timer. It may only be reconsidered when a later owner-published condition or evidence is supplied.
9. Interruption preserves evidence and pauses review. Cancellation withdraws a proposal before any authorized owner commit. Nonoccurrence is a valid, persistent interpretation of the evidence, not a failure.
10. Alternate outcomes must be retained where the accepted sources allow them. No branch may be silently removed because it conflicts with a desired historical result.

## 6. Character, Identity, and Uncertainty Gates

- An unresolved or disputed identity is held; it is never resolved by a convenient name match.
- A historical figure is not guaranteed to appear, and a possible role is not permission to create a person or character.
- A dynamic equivalent, if allowed at all, is governed solely by Historical Emergence and its separate owner gates; it may not inherit a historical identity or destiny.
- Conflicting or uncertain evidence remains uncertain in the review record. Confidence is not upgraded by repetition.
- No family, dynasty, relationship, office, title, claim, or succession state is created.

## 7. Military, Naval, Opening-State, and Runtime Gates

Where the required owner evidence is absent, the chain is held or does not occur.

No Opening State, Registry identity, active campaign state, runtime trigger, event instance, objective, mission, decision, AI action, applied consequence, payload, importer, asset, or production event ID is created.
