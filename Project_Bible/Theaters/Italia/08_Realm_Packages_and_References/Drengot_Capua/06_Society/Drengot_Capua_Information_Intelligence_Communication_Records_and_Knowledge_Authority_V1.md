## 1. Purpose

This authority defines what Drengot Capua, its characters, offices, institutions, armies, settlements, and external counterparts can know, how they learn it, how messages and records move, how information is assessed, how secrecy and deception operate, and how error, delay, contradiction, forgery, loss, and bias constrain decisions.

It does not create exact January 1062 informants, spies, messengers, archives, documents, codes, signals, reports, routes, knowledge states, or Opening State bindings.

```yaml
  - EstablishIntelligenceWarningSecrecyCounterintelligenceRumorAndDeception
  - ConnectInformationToEveryRealmSystem
  - PrepareExactOpeningInformationNetworkPreflight
```

## 2. Strong Information-System Verdict

Drengot Capua should be informationally capable but never omniscient. Richard can draw upon household followers, military reports, Papal and ecclesiastical contacts, Norman kinship channels, Capuan and Aversan participants, merchants, travelers, records, envoys, scouts, guides, and monastic institutions. These channels create reach and contradiction, not perfect truth.

```yaml
InformationVerdict:
  model: ActorSpecificSourceBoundedDelayedAndContestableKnowledge
  primary_strength: DenseHouseholdEcclesiasticalMilitaryAndDiplomaticChannels
  primary_weakness: DualCenterDelayBiasAndUnevenLocalKnowledge
  perfect_information: false
  shared_faction_mind: false
  AI_omniscience: false
  exact_opening_networks: Deferred
```
