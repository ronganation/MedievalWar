## 1. Purpose and Strong Memory Verdict

This authority defines how qualified Genoese actors, households, institutions, communities, occupational groups, commanders, clergy, merchants, and external counterparties may remember and interpret earlier destruction, recovery, legal protection, property, church continuity, maritime action, cooperation, conflict, loss, and claims. It does not assert that every Genoese actor shares one civic memory. It does not create memories merely because a historical fact existed.
