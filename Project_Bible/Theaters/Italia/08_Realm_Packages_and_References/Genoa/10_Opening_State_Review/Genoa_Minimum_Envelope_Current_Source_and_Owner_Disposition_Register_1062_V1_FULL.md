## 2. Mandate and Non-Mandate

This register performs four bounded jobs:

1. identifies the current working source for every minimum-envelope claim family;
2. records the owning authority and required owner receipt;
3. decides whether each claim family is eligible for exact Opening State drafting;
4. stops unsupported promotion while preserving a precise re-entry path.

This register does not select a ruler, officeholder, commander, household, settlement boundary, harbor configuration, treasury balance, goods stock, recruitment value, army, fleet, diplomatic relationship, outbreak, event, objective, payload, importer record, save record, map asset, battle asset, or Unreal object.
