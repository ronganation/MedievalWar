## 4. Functional playability versus exact truth

A future review-only Opening State could **propose** collective consultation, an institutional bishopric interface, and finite urban-harbor functions without claiming a named prince or a completed commune. This file does **not** choose the controller, create an anonymous officeholder, mandate an original commander, or instantiate a generic army merely because another faction uses those solutions. The Pisan Opening State demonstrates a method for recording selected, held and excluded fields, but its campaign-original commander and Pisan candidates are **not Genoa selections**. [Internal: turn99search192, turn99search187, turn99search176.]

The most consequential design question for the next gate is not whether every unknown can be filled. It is which *minimum functional starting capabilities* must exist for a coherent new campaign, and which owner can support each without disguising a synthetic gameplay choice as a historical fact. A candidate original character, if ever needed, must be openly labeled campaign-original and separately justified, admitted and provisioned. An unknown holder is not an empty office; an unselected force is not a historical zero. [Internal: turn99search192, turn99search209, turn99search213, turn99search176.]
