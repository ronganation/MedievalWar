## 2. Authority justification and anti-duplication boundary

The Sicilian diplomacy authority defines contact, negotiation, agreement, and external-owner consent. This authority owns the independent lifecycle that precedes and surrounds those decisions: observation, recording, transmission, authentication, interpretation, confidence, dissemination, secrecy, interception, deception, warning, and correction.

```yaml
IndependentLifecycleNeed:
  information_claim_may_exist_without_diplomatic_relationship: true
  military_warning_may_exist_without_negotiation: true
  rumor_may_spread_without_official_message: true
  intercepted_message_may_affect_knowledge_without_changing_agreement: true
  secrecy_and_counterintelligence_require_distinct_validation: true
  dedicated_authority_justified: true
```

The developed-Realm benchmark is methodological, not factual. The <File>Hammadid_Information_Intelligence_Messengers_Rumor_and_Counterintelligence_Authority_V1.md</File> separates world state, known state, belief, rumor, reports, delivery, understanding, and actor knowledge. The Sicilian authority adopts those separations while replacing the Hammadid court-centered problem with a multi-center island information problem.
