## 1. Purpose and Decision Standard

This audit resolves the conditional Venice question concerning intelligence, counterintelligence, operational security, agents, interception, surveillance, infiltration, deception, and information exploitation. It tests whether Venice needs a new standalone intelligence authority or whether the complete lifecycle is already owned across current information, diplomacy, governance, military, law, domestic-order, character, economy, geography, ecclesiastical, campaign, and Realm AI authorities.

```text
Data != Information
Information != Knowledge
Knowledge != Truth
Contact != Access
Access != Collection
Rumor != Intelligence
Report != Verified Fact
Secrecy != Invisibility
Suspicion != Evidence
Interception != Understanding
Deception Attempt != Deception Success
Agent Definition != Agent Instance
Office != Spy Network
Commercial Contact != Public Informant
Foreign Origin != Hostility
Private Thought != Observable State
```

A new authority is admitted only if the capability is materially absent, lacks viable owner routes, cannot be closed through targeted currentness actions, adds Venice-specific capability rather than symmetry, and remains definition-only without inventing opening agents, networks, targets, operations, secrets, or foreign private state.
