## 1. Strong Catalogue Verdict

Venice requires a broad but nonactivating catalogue of historical incidents, developments, negotiations, crises, opportunities, objective families, and theater interactions. The catalogue preserves researched historical possibilities and campaign-generated analogues without turning history into a mandatory event sequence.

This authority sits between historical interpretation and future event-system execution. It identifies what kinds of situations Venice may plausibly encounter, which owners must participate, which world conditions matter, and which outcomes must remain possible. It creates no active event, objective, person, office, agreement, project, army, fleet, territory, privilege, memory, momentum, emergence pathway, or successor realm.

```text
Historical Fact != Event
Historical Reference Date != Trigger
Event Definition != Event Instance
Event Instance != Owner-State Mutation
Objective != Command
Opportunity != Free Reward
Crisis != Guaranteed Catastrophe
Historical Analogue != Mandatory History
Dynamic Equivalent != Historical Person Reskinned
Event Chain != Emergence
Emergence != Script
No Event != System Failure
Recorded History != Required Campaign Future
```

## 2. Purpose and Corrected Ownership

The immediate source correctly established that later Venetian history should be treated as conditional and causal. Its six trajectory families, governing rule, Contarini closing phase, Byzantine-Norman crisis, 1082 privilege boundary, crusading possibilities, Adriatic contestation, and Fourth Crusade firewall are all preserved here. The correction is one of ownership and depth: those subjects become catalogue families and historical analogue windows rather than a second Historical Emergence authority.

### 2.1 This catalogue owns

- Venice-specific historical event and development definition families.
- General-event adaptations required by Venice's lagoon, maritime, ducal, ecclesiastical, commercial, and Adriatic conditions.
- Venice-facing Italia, Adriatic, Byzantine, papal, imperial, Croatian, Dalmatian, crusading, and maritime-theater interaction families.
- Historical analogue references and dynamic-equivalent permissions.
- Event-family eligibility inputs, blockers, participant classes, possible stages, outcome portfolios, and owner handoffs.
- Objective-family candidates associated with valid events and current strategic needs.
- Future-framework reconciliation requirements.

### 2.2 This catalogue does not own

- Historical fact, evidence authenticity, chronology adjudication, or uncertainty selection.
- Active Historical Memory, Momentum, or Emergence state.
- Exact January 1062 people, offices, titles, institutions, settlements, routes, property, agreements, forces, vessels, or resources.
- Event scheduling, random event firing, AI execution, player choice resolution, or runtime consequence application.
- Canonical Registry records, Opening State records, payloads, importers, save schema, or Unreal implementation.

## 20. Validation and Negative Fixtures

### 20.1 Positive fixtures

- A real ducal vacancy may generate consultation and settlement without selecting a successor automatically.
- A Byzantine request may generate negotiation, assistance, refusal, or nonoccurrence depending on actual state.
- A Dalmatian city relationship remains city-specific and may end in access, protection, neutrality, contest, or withdrawal.
- A St. Mark's project requires sponsors, rights, material, labor, funding, acceptance, and maintenance.
- A crusading transport proposal may be accepted, narrowed, redirected, refused, or fail.
- Campaign-generated convoy losses may produce petitions, repair objectives, route diversification, or no major political event.
- Historical identity may be replaced by a dynamic equivalent only without identity inheritance.

### 20.2 Fatal negative fixtures

- Fail if a historical date creates an event.
- Fail if an event creates a person, office, fleet, army, money, privilege, territory, or project without the owning system.
- Fail if Adriatic relevance becomes uniform control.
- Fail if an event catalogue entry becomes an active Opening State record.
- Fail if Momentum directly activates an event.
- Fail if an objective becomes a command or free reward.
- Fail if the 1082 privilege appears at the 1062 opening.
- Fail if the Fourth Crusade is guaranteed.
- Fail if a dynamic equivalent inherits a historical identity or destiny.
- Fail if an advanced save is overwritten by historical expectations.
