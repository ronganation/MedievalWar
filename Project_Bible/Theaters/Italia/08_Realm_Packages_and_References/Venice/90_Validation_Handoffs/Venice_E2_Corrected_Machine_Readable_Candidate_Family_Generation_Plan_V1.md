## 17. Failure-Disposition Matrix

| Failure | Disposition | Promotion effect | Rollback |
|---|---|---|---|
| Generation authorization missing | StopBeforeGeneration | Blocked | None required |
| JSON parse failure | Reject successor artifact | Blocked | Delete temporary successor |
| Schema self-validation failure | Reject schema successor | Blocked | Restore copied predecessor evidence |
| Payload schema failure | Quarantine payload and schema | Blocked | Delete unaccepted successor package |
| Section mapping mismatch | Reject payload | Blocked | Regenerate from approved matrix only |
| Owner-routing gap | Quarantine routing and payload | Blocked | Preserve predecessor routing |
| Generic owner placeholder remains | Reject routing successor | Blocked | No owner receipt generated |
| Temporal mismatch | Reject full family | Blocked | Delete successor family |
| Hash mismatch | Quarantine affected file | Blocked | Rebuild manifest after root-cause review |
| Repeat-generation mismatch | Reject deterministic-generation claim | Blocked | Preserve both outputs as evidence |
| Any mutation attempt | Fatal stop | Blocked | Restore snapshot and record violation |
