## 2. Historical Memory Doctrine

The past remains politically active through evidence, narration, custody, repetition, commemoration, suppression, reinterpretation, and audience reception.

```text
Fact != Evidence
Evidence != Testimony
Testimony != Narrative
Narrative != Memory
Memory != Commemoration
Commemoration != Legacy
Legacy != Reputation
Reputation != UniversalTruth
MemoryHolder != SubjectOfMemory
Knowledge != Belief
Belief != Agreement
Agreement != Loyalty
SacredMemory != AutomaticLegitimacy
GenealogyClaim != ProvenDescent
LaterSaga != OpeningKnowledge
LaterEpithet != OpeningTrait
HistoricalReconciliation != UniversalHistoricalTruth
```

A fact may exist without being known. Evidence may exist without being accessible. Testimony may conflict. Narrative may be selective. Memory may be sincere but inaccurate. Commemoration may be strategic. Legacy may change after death. Reputation is audience-specific and belongs to its proper owner.

## 32. Validation Portfolio

- suppressed memory becomes public after load;

- migrated IDs duplicate memory states;
- holder-specific interpretation collapses;
- second load changes memory state;

- an audience interpretation lacks current visibility;

Warnings do not lower fatal rules.
