## 2. Reconciliation Corrections Preserved

- Thorfinn's historical-person ID remains `Character.Historical.Orkney.ThorfinnSigurdsson`.
- Håkon's canonical ID is not a deprecated self-alias.
- Generic Olaf and Magnus references require contextual review or quarantine.
- The combined Paul-and-Erlend ID cannot direct-alias to either individual.
- Opening Archbishop references remain invalid or quarantined, not historical aliases.
- Scenario flags remain compatibility or derived references rather than competing truth.
- Unreal structures and resolver ownership remain in the shared runtime migration architecture.
- Candidate source, evidence, chronology, site, route, Memory, Momentum, Emergence, and authority identifiers remain candidate until their controlling Registry owners decide otherwise.

## 3. Purpose

The registry prevents duplicate characters, ambiguous royal and ecclesiastical identities, Orkney ruler collapse, cross-Realm duplication, save incompatibility, filename-dependent logic, deprecated identifiers entering new saves, definitions becoming runtime state, and migration resetting Campaign history.

This authority creates no characters, titles, offices, institutions, claims, routes, sites, Memory states, Momentum states, Emergence pathways, events, or outcomes.

## 4. Core Migration Rules

- Display names and filenames are never primary identifiers.
- Canonical IDs use ASCII characters.
- Historical diacritics remain in display names.
- Direct aliases resolve once to canonical IDs.
- Alias chains are prohibited.
- Deprecated IDs are never written into new saves.
- One historical person has one active runtime character identity.
- Historical figures use `Legacy.*` or `Character.Historical.*` when not living at opening.
- People, titles, offices, institutions, claims, Dynasties, power centers, sites, routes, facts, evidence, Memory, Momentum, and Emergence remain separately typed.
- Cross-Realm people retain one canonical character ID.
- Unknown required IDs fail safely or enter owner-approved quarantine.
- Migration changes identity representation. It does not create missing owner state.
