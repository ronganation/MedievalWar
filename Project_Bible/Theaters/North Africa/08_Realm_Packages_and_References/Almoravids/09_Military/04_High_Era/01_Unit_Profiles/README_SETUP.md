# Almoravid High Era Unit Profile Folder Setup

Extract the contents of this ZIP directly into the existing `04_High_Era_Roster/01_Unit_Profiles` folder.

Then double-click `SORT_HIGH_ERA_PROFILES.cmd`.

The package creates the four battlefield-family folders, creates High Era I and II subfolders, supplies four lightweight Early carryover Markdown placeholders, and moves the five exact current High Era profiles when those profiles are present at the root of `01_Unit_Profiles`.

No profile is renamed or deleted. No research or architecture file is moved.
