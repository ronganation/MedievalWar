## 1. Purpose

This audit prevents the Hammadid package from being declared complete merely because its current authority-family index looks broad. It requires comparison against relevant developed Realm packages and project-wide developed-Realm compatibility reviews before package freeze.

The comparison is capability-based, not filename-based. It may recommend a new Hammadid file only when a substantive capability is absent, cannot be cleanly owned by an existing authority, matters to Hammadid gameplay or implementation, and is supported by evidence or an explicit design need.
