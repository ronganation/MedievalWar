## 0.2. Strong Memory Verdict

The Zirid package possesses rich historical subjects that can shape dynastic legitimacy, court policy, juristic argument, urban relationships, diplomacy, military caution, public narrative, and player understanding. Those subjects do not become universal memory merely because the project knows them.

This authority therefore binds every memory to an eligible holder or holder class, a transmission path, an acquisition event or continuity basis, a confidence state, visibility, contestation, current meaning, information owner, and affected domain. Memories may be incomplete, selective, disputed, strategic, inherited, recorded, performed, suppressed, revived, or transformed. They never directly create historical truth, rights, claims, relationships, resources, loyalty, modifiers, events, or outcomes.
