## 2. Refinement Verdict

West Francia remains the principal campaign Theater for the Capetian Crown and the powerful territorial principalities whose rival authorities, family networks, routes, markets, churches, and armed capacities define the western Frankish political world at the January 1062 opening.

The V1 strategic thesis remains controlling: the Crown provides a common political horizon, but power is territorial, personal, negotiated, and unevenly enforceable. V2 modernizes authority boundaries, verified package associations, cross-Theater ownership, temporal control, Registry and Opening State separation, importer and save requirements, implementation sequencing, and validation discipline. V2 does not create a single West Francia faction, political order, court, treasury, army, diplomacy block, culture, law, knowledge state, or runtime store.

```text
West Francia Theater != Kingdom of France
Theater Association != Vassalage
Royal Recognition != Direct Administration
Dynastic Connection != Alliance
Same Theater != Shared Knowledge
Canonical Reference != Active State
Static Authority != Runtime Implementation
```
