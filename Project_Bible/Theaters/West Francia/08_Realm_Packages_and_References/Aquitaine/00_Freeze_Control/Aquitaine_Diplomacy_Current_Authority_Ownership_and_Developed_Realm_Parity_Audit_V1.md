## 1. Independent Verdict

The current Aquitaine package index does not list a general Realm diplomacy and external-relations authority. It lists ten first-pass specialist Markdown authorities covering Territory, Routes and Communication, Communities, Economy, Military, Recruitment, Supply, Law, Titles and Claims, and an Opening Campaign Opportunity reservation. It separately lists Character Network, Dynasty, Governance, Ecclesiastical, Realm AI, Historical systems, Opening State, and the ID Registry. None is assigned ownership of the complete diplomatic lifecycle.

The exact and broad enterprise searches did not surface an Aquitaine file explicitly titled or described as a general diplomacy, external-relations, agreement, war-peace, recognition, tribute, hostage, clientage, or political-settlement authority. The search did surface Aquitaine package navigation and historical material, but not a current general diplomacy owner.

This is a demonstrated substantive ownership gap, not a symmetry-only gap. Aquitaine requires one new combined authority for Knowledge, Communication, Diplomacy, and External Relations, or one equivalently scoped general diplomacy authority. It must consume the existing specialist owners without replacing them and must not create opening diplomatic instances, activate Barbastro, promote a Papal request, script Bernard II's rebellion, or invent external-owner responses.

## 5. Aquitaine-Specific Diplomatic Thesis

Aquitaine should not be presented as a generic French duchy with one relationship score. The current index establishes several design facts that should control the missing authority:

- Aquitaine is a negotiated government whose current ruler is William VIII.
- The Realm contains meaningful Poitevin, Gascon, Lusignan, Thouars, dynastic, ecclesiastical, territorial, route, military, and local-power interfaces.
- The package distinguishes a full playable Realm, bounded Major Regional Powers, lightweight Local Lordships, and event- or conflict-bound rebellion or irregular forces.
- Regional Power does not equal generic rebel, and nonplayable does not equal politically meaningless.
- War is available without a casus belli, claim, or Papal-permission gate.
- Claims modify reactions but do not unlock war.
- Papal standing remains separate from diplomatic reliability, bilateral relations, treaty performance, threat, sanctions, and reconciliation.
- Barbastro is a conditional opportunity, not an opening invitation, Papal request, commitment, commander, force, route plan, or mandatory event.
- Bernard II Tumapaler is a former rival and potential reconciliation, neutrality, claimant, coalition, or resistance interface, not a scripted rebel.

The appropriate identity for the new authority is therefore a negotiated, regionally plural, route-dependent ducal diplomacy that can coordinate without erasing local powers and can pursue external opportunity without date scripting.

## 6. Required General Diplomacy Coverage

One new authority should own Aquitaine-specific definitions and coordination for:

1. diplomatic principals, representatives, audiences, mandates, ratification, continuity, and revocation;
2. directional contact, knowledge, communication, recognition, and external-owner locks;
3. proposals, counterproposals, reservations, delivery, receipt, understanding, acceptance, rejection, delay, expiry, and ratification;
4. agreements, clauses, obligations, capacity, reservation, mobilization, execution, delivery, inspection, acceptance, breach, cure, remedy, mediation, appeal, withdrawal, termination, and archive;
5. war entry, bounded objectives, escalation, contribution, command, occupation boundaries, withdrawal, and settlement paths;
6. coalitions, member-specific contribution, shared command, separate peace, and external-service arrangements;
7. ceasefire, truce, peace, reconciliation, recognition, and political settlement;
8. crossing, passage, safe conduct, maritime access, landing, staging, hospitality, and return agreements without creating route or transport capacity;
9. trade access, gifts, tribute, ransom, subsidy, compensation, restitution, guarantees, security, toll terms, and payment performance without creating treasury or goods;
10. marriage negotiation, wards, hostages, prisoners, refuge, sanctuary, restoration, and safe return without person ownership;
11. homage, service, protection, clientage, submission, autonomy, retained government, and holding-specific obligations without automatic annexation;
12. domestic sustainability, AI evaluation, player explanation, Save, Migration, determinism, atomic commit, rollback, validation, and phased handoff.

The authority should combine Knowledge, Communication, Diplomacy, and External Relations only if doing so avoids duplication with the existing Routes and Character Network owners. It must explicitly state that route communication defines feasibility and transmission, while the new authority owns diplomatic message and agreement lifecycles.

## 11. Validation Targets

The first authority version should include one consolidated numbered matrix covering at least:

- ruler is not identical to Realm or every principal;
- relationship is not recognition, alliance, or agreement;
- claim does not unlock war;
- Papal standing is not diplomatic reliability or permission;
- Regional Power is not generic rebel;
- former duke is not active claimant, rebel, or coalition leader;
- Barbastro does not activate by date;
- opening opportunity is not invitation, commitment, force, route, or war;
- route and communication do not create passage, safe conduct, or access;
- agreement does not create military, economic, Supply, or transport capacity;
- coalition does not create contribution or shared command;
- battle victory does not create possession, government, peace, or settlement;
- tribute is not tax, ownership, or submission;
- protected person is not property and protected minor lacks adult diplomatic agency;
- AI evaluation does not create command or expose hidden truth;
- external owner state cannot be authored locally;
- definition import creates no opening or runtime instance;
- Opening State never replays into an advanced save;
- cross-owner partial commit rolls back;
- equal authoritative inputs, versions, order, temporal states, and seed produce equal results;
- a second general Aquitaine diplomacy authority is prohibited after acceptance.

The package index states that `01_Core_Authorities` contains Registry, Opening State, characters, government, AI, and specialist authorities. No dedicated diplomacy folder exists in the actual Aquitaine root. Therefore the new authority belongs in the existing core-authority folder, not in a newly invented folder.

## 14. Final Audit Decision

Aquitaine's current package is broadly developed, but the package index demonstrates that general diplomacy remains the missing coordination owner between its specialist authorities. The next useful file is one new substantive Aquitaine combined Knowledge, Communication, Diplomacy, and External Relations authority in `01_Core_Authorities`, with companions later routed to `04_Preflights`.

This is not an implementation action and does not reopen Aquitaine's broad Realm design. It closes a specific developed-Realm parity and ownership gap while preserving the current correction gate for IDs, filenames, Opening State bindings, external-owner receipts, serialization, and future implementation evidence.
