## 2. Audit Purpose

This audit determines:

- which Aquitaine authority families are current;
- which predecessor files remain provenance only;
- which developed character profiles are available;
- which specialist authorities are still missing;
- which dependencies block exact Opening State binding;
- what can proceed to candidate serialization later;
- what must remain review-only, empty, deferred, or quarantined;
- whether Aquitaine can be frozen;
- the smallest safe next work sequence.

This audit does not redefine Aquitaine's history, characters, title structure, military roster, economy, geography, Papal relations, or Opening State.

## 3. Audit Rules

```text
Document exists != current authority
Current authority != project-canonical Registry adoption
Developed profile != active Opening State record
Registered definition != runtime instance
Title extent != direct possession
War availability != casus belli permission gate
Papal standing != diplomatic reliability
Static check != importer validation
Importer validation != runtime validation
Runtime validation != save, migration, replay, or performance validation
Core modernization complete != specialist package complete
```
