## 1. Verdict

Brittany has a strong, coherent V1 Realm package. The package does not need reinvention and must not be replaced by a thinner synopsis. The modernization program will preserve Brittany's established identity as a compact, high-agency duchy built around restored ducal authority under negotiated rule, then bring every retained authority into current constitutional, temporal, ownership, Historical Suite, military, Registry, and Unreal Engine 5.8 parity.

## 2. Copy-First Modernization Rule

Every successor must begin from the complete immediate substantive source. It must preserve all useful sections, records, tables, portfolios, uncertainty treatment, named participants, directed relationships, owner boundaries, migration notes, validation gates, player-facing consequences, and implementation interfaces unless a removal ledger demonstrates that material is outdated, incorrect, superseded, genuinely repetitive, or constitutionally incompatible.

```text
Copy complete source first
Preserve substance
Correct outdated control metadata
Integrate enrichment inside the authority
Compare source and successor directly
Record every justified removal
Run literal completeness checks
Claim only validation actually performed
```

A successor that is materially shorter or less useful than the source fails this portfolio gate unless the removal ledger justifies the difference section by section.
