## 4. Authority and Owner Boundaries

Historical Memory owns definitions, holder and audience interpretation, provenance references, acquisition, transmission, reception, confidence, salience, accessibility, visibility, commemoration, suppression, erosion, revision, collision, persistence, save state, and bounded downstream influence.

Historical Memory does not own historical truth, source authenticity, exact chronology, uncertainty selection, person identity, titles, claims, offices, households, laws, property, regions, military capacity, current relationships, foreign intentions, Momentum stages, Emergence pathways, Opening State activation, Registry publication, or Unreal runtime mutation.
