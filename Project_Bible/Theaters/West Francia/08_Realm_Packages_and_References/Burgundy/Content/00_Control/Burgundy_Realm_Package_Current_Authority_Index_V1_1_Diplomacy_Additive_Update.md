This file is the practical navigation index for the current Burgundy Realm package. It identifies the current authority for each subject, records preservation or supersession disposition, routes owners and dependencies, and prevents future work from selecting an older or preliminary file merely because that file remains searchable.

This index does not replace any substantive authority. If this index conflicts with a controlling substantive source, Project Bible 2.4, Design Expansion Checklist 3.7, the current substantive authority, and the relevant state owner control the result. The conflict must be recorded and the index corrected.
