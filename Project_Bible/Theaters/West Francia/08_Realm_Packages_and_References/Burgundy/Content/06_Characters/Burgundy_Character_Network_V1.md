## 2. Burgundy Network Thesis

Burgundy requires a sparse but expandable directed network around <Person>Robert I of Burgundy</Person>, adult dynasts, protected descendants, uncertain spouse interfaces, the external Capetian crown relationship, Semur grievance and reconciliation questions, regional service, ecclesiastical reception, household access, and succession preparation. Kinship supplies a basis for possible edges but never supplies trust, loyalty, command, consent, knowledge, or political alignment by itself.

```text
Relationship A to B != Relationship B to A
Kinship != Trust
Kinship != Loyalty
Marriage != Alliance
Marriage != Shared Knowledge
Dynasty Membership != Network Membership
Network Membership != Opening Activation
Basis Edge != Mutable Dimensions
Knowledge != Truth
Promise != Obligation
Obligation != Performance
Access != Authority
Grievance != Hostility
Support Intent != Installed Heir
Institution != Person
```
