## 9. Military Doctrine

Flanders does not use a generic linear unit-upgrade ladder or unlimited recruitment. The military package separates:

```text
Unit Family != Unit Instance
Recruitment Source != Recruitment Pool
Recruitment Pool != Recruited Force
Command Eligibility != Command Assignment
Garrison Priority != Soldier Count
External Contribution != Domestic Pool
```

Population informs finite pool availability and recovery but is not directly spent as army manpower. Military access depends on owner-controlled households, obligations, communities, offices, routes, equipment, mounts, treasury, supply, local defense, command, and recovery.
