# France UE5.8 Candidate DataAsset Drafts V1

This folder contains JSON source drafts for candidate DataAsset boundaries defined by the France UE5.8 candidate importer and schema handoff.

These files are not `.uasset` files. They have not been imported, compiled, registered, saved by Unreal Editor, or validated at runtime. All record arrays remain empty until a read-only importer dry run validates the current 27-item France candidate bundle.

The short folder and filenames are deliberate Windows path-length safeguards.
