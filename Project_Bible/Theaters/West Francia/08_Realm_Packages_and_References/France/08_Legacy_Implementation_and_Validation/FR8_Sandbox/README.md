# France UE5.8 Candidate Sandbox Module Patch V1

Candidate-only C++ source patch for an isolated Unreal Engine 5.8 review sandbox. Nothing in this package has been copied into the MedievalWar Unreal project, compiled, loaded by Unreal Editor, or registered at runtime.

The importer is deliberately read-only and returns a dry-run result. Commit, Registry promotion, alias execution, Opening State activation, DataAsset saving, and real payload import remain prohibited.

Short archive paths are used to avoid Windows error 0x80010135.
