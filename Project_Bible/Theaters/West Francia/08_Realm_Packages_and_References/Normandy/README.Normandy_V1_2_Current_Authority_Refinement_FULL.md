## 1. Purpose

This workspace contains the frozen Normandy Realm baseline for Medieval War.

Normandy serves as one of the primary reference implementations for Realm design, character integration, dynasty integration, campaign initialization, Opening State construction, political causality, and now Realm-specific diplomacy definition within the wider West Francia diplomacy review.

The Normandy package establishes:

- Normandy Opening State;
- Normandy character authorities;
- Normandy dynasty authorities;
- Normandy Realm authorities;
- Norman political structure;
- Norman succession structure;
- Norman historical baseline;
- Normandy knowledge, communication, diplomacy, and external-relations authority;
- bounded Registry and cross-owner preflight material for future diplomacy implementation preparation.

The Realm is frozen against broad redesign. Only compatibility, migration, validation, importer, compile, runtime, constitutional, temporal-model, ownership-boundary, formatting, demonstrated-defect, and genuinely missing specialist-capability corrections are authorized. Such corrections must remain copy-first, additive, non-destructive, owner-bounded, and honest about validation status.

The diplomacy addition is a bounded specialist-gap closure discovered during the West Francia diplomacy review. It does not reopen Normandy for broad Realm redesign and does not authorize further Normandy implementation work during the theater-level diplomacy pass.

## 6. Diplomacy Identity and Boundaries

Normandy diplomacy is defined as **Prepared Ducal Ambition, Reciprocal Service, Continental Brokerage, and Conditional Cross-Channel Transformation**.

```text
William Of Normandy != Normandy
Ducal Authority != Unlimited External Authority
Kinship != Consent
Marriage != Treaty
Recognition != Alliance
Alliance != War Entry
Claim != War Permission
Papal Interest != Papal Action
Proposal != Agreement
Agreement != Performance
Route != Passage
Passage != Safe Conduct
Safe Conduct != Supply
Port Access != Fleet Or Transport Capacity
Victory != Recognition
Recognition != Possession
Possession != Government
Government != Durable Succession
Unknown != Zero
Diplomatic Definition != Opening Binding
```

Normandy's diplomacy may consume owner-published state from characters, Character Network, dynasties, titles, claims, governance, households, law, church, geography, economy, military, Personality, AI, historical systems, and external Realms. It may not create those owners' state.

## 8. Temporal Authority

The Normandy package uses the controlling three-track strategic-turn model. A strategic turn does not represent one universal seven-month interval.

```yaml
temporal_model:
  Historical:
    advance_per_strategic_turn: 21_months
  Biological:
    advance_per_strategic_turn: 7_months
  Campaign_Season:
    advance_per_strategic_turn: 1_ordered_season_step
    opening_season: Winter
    ordered_cycle: [Winter, Spring, Summer, Autumn]
README_advances_any_track: false
```

Historical chronology and political elapsed time use the Historical track. Aging, maturation, fertility-age progression, and other biological development use the Biological track. Campaign operating conditions use the ordered Campaign Season track unless a controlling system authority assigns a more specific owner.
